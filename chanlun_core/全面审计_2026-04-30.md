## 二、一类买卖点 — 审计

### 2.1 counter_trend 检查 [已修复 ✅]

一买: L390-401, 检查 ZS9 之后是否出现 ZG > ZS9.ZG 的中枢
一卖: L456-463, 检查 ZS9 之后是否出现 ZD < ZS9.ZD 的中枢

作用范围: 所有调用链最终都走 `_find_first_class_points()`:

**结论: counter_trend 已全面生效，无遗漏。**

### 2.2 离开段查找逻辑 [需确认 ⚠️]

L406: `after_bis = [b for b in self.bis if b.end_date >= last_zs.end_date ...]`

问题: 使用 `end_date >= zs.end_date` 查找离开段。当离开段的笔在中枢形成中期就结束（而非中枢完成时），该笔的 end_date < zs.end_date，会被遗漏。

案例: 吉林敖东 ZS7(2026-03-09~04-24)，向下笔 3/17→3/23 已跌破 ZD(18.26)，但 end_date(3/23) < ZS7.end_date(4/24)，代码跳过它，选了后面 4/10→4/24 的笔。

**影响**: 没有漏掉真正的一买，但可能错过"中枢早期就跌破"的更强信号。当前设计保守合理。

### 2.3 进入段查找 [需确认 ⚠️]

L424: `enter_bi = reversed bis with end_date <= last_zs.start_date and direction == 'down'`

找到"中枢开始前的最近向下笔"。这个逻辑在一个中枢被多个下跌笔前后夹击时可能有歧义。但实际运行中未见错误。

### 2.4 背驰判定 [OK ✅]

L437: `leave_area < enter_area * self.divergence_threshold`

divergence_threshold 默认为 1.0，即离开段面积 < 进入段面积（严格小于）。MACD 面积用绝对值之和，正确反映两段力度对比。

## 三、二类买卖点 — 审计

### 3.1 一买依赖性 [隐含问题 ⚠️]

二买完全依赖 `first_class_points` 参数。如果一买被 counter_trend 阻止 → 二买也不会产生。这个行为正确。

**但有一个隐蔽问题**: 如果一买在某个时间点"技术上成立"但被 counter_trend 阻止，而此时恰好有一个满足二买条件的回调——它不会产生二买。因为二买需要先有一买。

**影响**: 无实际影响。没有一买的二买在缠论上不成立。

### 3.2 创新低判定 [OK ✅]

L543: `callback_low >= fc_point.price * (1 - second_class_tolerance)`

默认容差 1%。就是说回调低点不低于一买价的 99% 即算"不创新低"。合理。

### 3.3 只取第一次回调 [OK ✅]

L533-536: 找一买之后的**第一个**向下笔。符合缠论定义。

## 四、三类买卖点 — 审计

### 4.1 中枢遍历范围 [需确认 ⚠️]

L597-601: 对**所有**中枢都检查三买。包括很老的中枢。

问题: 一个 2024 年的老中枢，如果在 2026 年被突破并回踩，也会产生三买。缠论上这是正确的（任何级别的中枢被突破都是信号），但实际中很老的中枢参考价值降低。

`dedup_by_nearest_zs` (L652-658) 部分缓解: 同一日期产生的多个三买候选只保留最近中枢的。

### 4.2 三买判断逻辑 [OK ✅]

L603-625: 
1. 向上笔突破 ZG → found_up_break = True
2. 向下笔回踩 → 如果不破 ZG，形成三买候选
3. 再次向上笔 → 确认为三买

符合缠论标准流程: 突破 → 回踩 → 确认。

### 4.3 三卖镜像 [OK ✅]

L627-649: 与三买完全镜像。

### 4.4 后处理去重 [OK ✅]

L676-683: 按 (type, level, date) 去重。
L685-686: 按日期排序。

**注意**: 去重后不同级别的买卖点可以在同一天共存（如三买+二买同一天），这是正确的——不同级别代表不同结构确认。

## 六、趋势识别 — 审计

### 6.1 中枢下移判定 [OK ✅]

L355: `zs2.zg < zs1.zd`

含义: 后中枢的**上沿**低于前中枢的**下沿**。确保中枢完全下移，不留重叠。这个比"ZG<ZG"更严，防止中枢扩张被误判为趋势。

### 6.2 趋势连续性 [OK ✅]

L356-365: 连续的中枢下移会被合并到同一趋势中。趋势长度的最小要求是 2 个中枢 (L368)。
