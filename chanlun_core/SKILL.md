# 缠论择时分析

基于缠论理论对个股进行技术分析，识别分型、笔、线段、中枢，定位一二三类买卖点，辅助盘前择时决策。

## 使用场景

- 盘前分析某只股票，判断当前是否处于买点或卖点附近
- 复盘个股历史走势中的中枢结构和趋势演变
- 识别个股的一二三类买卖点位置
- 判断当前走势处于哪个级别的中枢震荡或趋势中

## 执行步骤

### 第一步：确认分析标的

从用户输入中提取股票名称或代码。如果用户只提供了名称，使用 `hexin-ifind-ds-stock-mcp_get_stock_info` 工具查询股票代码。

### 第二步：获取K线数据

使用 `hexin-ifind-ds-stock-mcp_get_stock_performance` 工具获取该股票的**完整日K线数据**。

**必须分两次查询以获取完整的 OHLCV 数据：**

1. **第一次查询**：获取开盘价、最低价、收盘价、成交量
   ```
   查询：{股票名称} {股票代码} {起始日期} 到 {结束日期} 的日K线数据，包括开盘价、最低价、收盘价、成交量
   ```

2. **第二次查询**：获取最高价
   ```
   查询：{股票名称} {股票代码} {起始日期} 到 {结束日期} 的日K线最高价
   ```

**数据范围选择策略**：
- 默认获取近3年数据（足够形成多个中枢和趋势）
- 如果用户指定了时间范围，按用户要求获取

### 第三步：整理数据并保存为JSON文件（关键步骤）

**这一步至关重要，必须严格执行，否则分析脚本会使用模拟数据导致结果错误。**

将第二步获取的 iFind 真实数据整理为 JSON 格式，保存到文件中：

1. **解析 iFind 返回的数据**，提取每个交易日的 OHLCV（开盘价、最高价、最低价、收盘价、成交量）

2. **创建 JSON 文件**，格式如下：
   ```json
   [
     {"date": "2023-04-04", "open": 16.15, "high": 16.25, "low": 15.9, "close": 15.99, "volume": 19240708},
     {"date": "2023-04-06", "open": 15.84, "high": 15.99, "low": 15.81, "close": 15.89, "volume": 10853254},
     ...
   ]
   ```

3. **保存路径**：`{workspace}/chanlun/{股票代码}_klines.json`（如目录不存在需先创建）

4. **数据完整性检查**：
   - 确保包含 iFind 返回的所有数据点（通常是关键日期的采样数据）
   - 日期格式统一为 `YYYY-MM-DD`
   - 成交量如果是"万"单位，需转换为股数（乘以10000）

### 第四步：运行缠论分析

使用 bash 工具运行分析脚本，**必须通过 `--data` 参数传入第三步保存的 JSON 文件**：

```bash
cd "{workspace}/chanlun" && python "{skill_dir}/generate_analysis.py" --code {股票代码} --name {股票名称} --start {起始日期} --end {结束日期} --data {股票代码}_klines.json
```

其中 `{skill_dir}` 为本 Skill 所在目录：`~/.alphaclaw/skills/chanlun-timing-analysis`

**重要**：
- `--data` 参数是必须的，指向第三步创建的 JSON 文件
- 如果不传 `--data` 参数，脚本会使用模拟数据，导致分析结果与实际行情不符
- 脚本位于本 Skill 目录下：`~/.alphaclaw/skills/chanlun-timing-analysis/generate_analysis.py`

### 第五步：解读分析结果

从脚本输出中提取关键信息，向用户汇报：

**必须包含的内容：**

1. **当前位置判断**
   - 当前处于第几个中枢？中枢区间是多少？
   - 当前价格相对于最近中枢的位置（上方/内部/下方）
   - 最近一笔的方向（上升笔/下降笔）

2. **最近买卖点信号**
   - 最近出现的买卖点类型（一/二/三类）
   - 买卖点出现的日期和价格
   - 距今多少个交易日

3. **择时建议**
   - 如果最近有买点且当前价格接近买点价格 → 提示"接近买点区域"
   - 如果最近有卖点且当前价格接近卖点价格 → 提示"接近卖点区域"
   - 如果处于中枢震荡中 → 提示"震荡区间，等待方向选择"
   - 如果处于趋势延续中 → 提示趋势方向和潜在目标

4. **关键价位**
   - 最近中枢的上沿（ZG）和下沿（ZD）
   - 最近的顶分型和底分型价格
   - 重要支撑位和压力位

### 第六步：交付可视化

1. 使用 bash 工具在浏览器中打开生成的 HTML 文件（HTML 输出在 `{workspace}/chanlun/` 目录下）：
   ```bash
   start "" "{workspace}/chanlun/{股票代码}_chanlun_analysis.html"
   ```
2. 告知用户文件保存路径
3. 简要说明网页交互功能（图层开关、时间范围筛选、缩放拖拽）

## 缠论核心概念速查

供分析时参考：

**分型**：三根K线，中间一根的高点最高（顶分型）或低点最低（底分型）

**笔**：连接相邻的顶分型和底分型，中间至少有5根K线

**中枢**：至少3笔重叠的价格区间，ZG为重叠区上沿，ZD为重叠区下沿

**买卖点定义**：
- 一类买点：下跌趋势中，最后一个中枢的第三类卖点后的下跌段出现背驰
- 二类买点：一类买点后的第一次回调不创新低
- 三类买点：离开中枢后的回踩不进入中枢

**背驰判断**：价格创新低/新高，但MACD黄白线或柱状面积不创新低/新高

## 注意事项

1. **数据必须使用真实数据**：必须通过 `--data` 参数传入 iFind 数据文件，否则脚本会使用模拟数据导致结果错误
2. **数据质量**：确保获取的K线数据完整，缺失数据会影响分型和笔的识别
3. **级别意识**：日线级别的买卖点适合中线操作，短线需结合更小级别
4. **结合基本面**：缠论是技术分析工具，重大基本面变化可能使技术形态失效
5. **风险提示**：买卖点是概率性信号，不是确定性结果，需结合仓位管理
6. **动态更新**：每个交易日收盘后数据会更新，分析结论需要定期刷新
