# A500 Scoring Change Log

## 2026-06-10 — 跌破买点惩罚缺失（一买/二买）

**发现的 bug**：`validate_tech_score.py` 的 `compute_technical_score()` 有7个评分维度，维度6（`zs_break_penalty`）仅对三买做了跌破中枢ZD检查，一买/二买完全没有「当前价 vs 买点价」的保护。

**触发场景**：用户在2026-06-10 A500选股结果中发现惠泰医疗(-14.4%)、长春高新(-21.7%)、视源股份(-8.5%)跌破买价后技术分仍>50。

**根因**：2026-05-29 修复三买跌破中枢无惩罚（Bug 3）时只做了三买，遗漏了一买/二买。

**修复方案**：新增维度8 `buy_price_penalty`，按跌幅分级扣分（一买-30~-10，二买-20~-10），>2% 噪声容差。

**状态**：待实施。

## 2026-06-10 — pyarrow/fastparquet 依赖修复

**问题**：DataManager parquet 缓存引擎无法写入 → 所有 K 线数据需从 Baostock 重新拉取 → Phase 2+3 从 12min 飙升到 34min。

**修复**：`pip install pyarrow fastparquet`。

**验证**：import pyarrow (24.0.0), import fastparquet (2026.5.0)。

**后续**：下次 A500 运行时自动利用 parquet 缓存加速。
