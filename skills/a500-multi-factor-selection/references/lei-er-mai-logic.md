# 类二买（反转后类二买）逻辑详解

## 定义

趋势反转后，在新中枢下半区出现的回踩买点。不是标准缠论二买，而是系统扩展的买点类型。

**模式标识**：`类二买(趋势反转后,中枢下半区+MACD改善)`

## 触发条件（pool_scanner.py 第159-181行）

四步检测：

1. **趋势反转确认**：找到下跌趋势最后一个中枢（downtrend_last_zs），之后出现反向中枢（counter_zs，ZG更高）
2. **无标准三买**：反向中枢后30天内没有标准三买（level=3）
3. **价格位置**：当前价格在反向中枢下半区，即 `ZD ≤ price ≤ (ZD+ZG)/2`
4. **MACD改善**：DIF>DEA 或绿柱缩短（动量确认）

## 与标准二买的核心区别

| 维度 | 标准二买 | 类二买（反转后） |
|------|----------|------------------|
| 理论依据 | 一买后的第一次回调不创新低 | 趋势反转后新中枢的回踩 |
| 前置条件 | 必须先有标准一买确认 | 只需趋势反转确认 |
| 评分 | 5分（最高） | 3分（中等） |
| 可靠性 | 高 | 中等 |
| 出现频率 | 极低（510只中仅1只） | 较高（典型10-15只） |
| 缠论依据 | 原教旨 | 扩展（走势终完美） |

## 评分逻辑

- **score = 3**（与反转后三买相同，低于标准二买5分）
- 理由：没有标准二买那么强的确认（需先有一买），但有趋势反转+位置+动量三重支撑
- 仓位建议：技术分≥60时建议30%仓位

## 2026-05-30 实跑统计

- 推荐30只中类二买占10只（33%）
- 平均综合分65.4（低于类一买68.8，高于三买62.4）
- 平均技术分62.5（偏低，技术结构非最强）
- 平均Alpha分67.7（因子排名表现较好）
- 平均基本面分68.9（基本面普遍不错）

## 解读要点

1. **类二买占比高** → 市场处于趋势反转阶段，许多股票出现反转后结构
2. **技术分不高但Alpha分高** → 这些股票靠基本面和动量因子驱动，非纯技术面强势
3. **仓位建议谨慎** → 只有技术分≥60的才有30%仓位，低于60的为0%
4. **优先级**：类一买(68.8) > 类二买(65.4) > 三买形成中(65.0) > 三买(62.4)
