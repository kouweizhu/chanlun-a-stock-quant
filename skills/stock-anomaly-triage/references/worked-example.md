# 股票异动归因 — 工作示例

## 示例场景

用户问："海康威视今天为什么跌？"

## 并行三路（伪代码级）

### ① 资金面（mx-financial-assistant）

```python
# 查当日行情
mx_finance_data(query="海康威视 002415 今日分时 涨跌幅 成交量")

# 查主力资金
mx_finance_data(query="海康威视 002415 主力资金流向 大单")

# 查量比
mx_finance_data(query="海康威视 002415 量比 5日均量")
```

预期返回示例：
```
涨跌幅: -3.2%
主力净流入: -1.8亿（特大单-1.2亿，大单-0.6亿）
量比: 1.8（放量下跌）
```

### ② 消息面（同花顺 news-search）

```python
iwencai_news_search(query="海康威视 最新公告 新闻")
```

预期返回示例：
```
- 16:02 海康威视：股东减持计划公告（利空）
- 14:30 美国众议院提案限制安防设备进口（利空）
- 10:15 海康威视回应：相关业务占比极小（中性偏正面）
```

### ③ 实时搜索（web_search）

```python
web_search(query="海康威视 下跌 原因 2026-05-22")
# 或
bing_search("海康威视 跳水 利空")
```

预期返回示例：
```
- 财联社：美国拟将更多中国安防企业列入实体清单（利空）
- 雪球：市场传闻某基金大幅减仓安防板块
```

## 交叉验证输出

```
002415 海康威视 -3.2%  2026-05-22
├─ 核心归因：美国众议院提案限制安防设备进口，叠加股东减持公告，双重利空共振
├─ 资金面：主力净流出1.8亿，特大单主导流出，放量下跌（确定性: 高）
├─ 消息面：股东减持公告 + 美国提案（确定性: 高）
├─ 传闻：某基金减仓安防板块（确定性: 低，消息面已充分解释跌幅）
└─ 综合判断：利空驱动明确，短期承压但需关注公司回应中"业务占比极小"是否被市场消化
```

## 注意事项

1. **只查当天**：异动归因只关注当日，不拉历史数据
2. **多路不等待**：三条路同时发，不要先等①出结果再发②
3. **排他性判断**：如果能从公告/官方找到明确原因，传闻层可以不报或少报
4. **涨跌都查**：不论大涨还是大跌，流程一样
5. **停牌/复牌**：如果查不到分时数据，可能是停牌/刚复牌，走 web_search 确认
