## 算子与因子的关系

**算子 = 因子计算公式的基本原子操作。** 19 个基础算子分三类：

| 类别 | 算子 | 说明 |
|------|------|------|
| **截面类**（一天内跨股票） | `rank(df)` | 当天所有股票的百分位排名 |
| | `scale(df, a)` | L1归一化 |
| | `safe_div(a, b)` | 防除零除法 |
| **时序类**（单只股票跨天） | `ts_mean/ts_std/ts_max/ts_min` | 均线/标准差/极值 |
| | `ts_corr/ts_cov(x, y, n)` | 两序列滚动相关性 |
| | `ts_rank(df, n)` | 当前值在n日窗口中的排位 |
| | `ts_argmax/ts_argmin(df, n)` | 极值出现的相对位置 |
| | `delta(df, d)` | d日差值（d>=1，防未来函数） |
| | `decay_linear(df, n)` | 线性衰减加权均线 |
| **变换类** | `signed_power(df, p)` | 保号幂变换 |
| | `vwap(panel, market)` | 市场均价（A股单位换算） |

**因子 = 算子组合成的有交易含义的公式。** 例如：
```
算子组合: delta(safe_div((close-low)-(high-close), high-low), 1)
    因子: gtja191_002 = "日内收盘位置变化"
```

## 因子 1: gtja191_171 — 最强幸存者

**IC=0.0432, IR=0.2690** — 191个GTJA因子中 IC 最高

```
公式: -1 * ((close - low) * open^5) / ((close - high) * close^5)
```

**它在问：** 相比收盘价，今天开盘价在什么位置？

**拆解：**
- `(close - low)` = 收盘距最低点距离
- `(close - high)` = 收盘距最高点距离（负值）
- `open^5` 和 `close^5` 作为指数权重放大差异，5次方使开盘/收盘价的小差异被剧烈放大

**含义：** 收盘靠近最低点 + 开盘价高 = 因子值大。乘-1后反向。本质是捕捉**日内K线的形状不对称性**——是否"开盘冲高、收盘回落"。幸存原因：这类形态效应被大量价策略忽略。

**缠论映射：** 等价于捕捉日线分型的"上影线/下影线不对称性"。三买信号 + 该因子值高 → 日内结构健康，中枢支撑有效。

**数据需求：** open, high, low, close 四列即可。

## 因子 2: gtja191_111 — 量价形态趋势

**IC=0.0349, IR=0.2232**

```
公式: sma(v * ((c-l)-(h-c))/(h-l), 11, 2) - sma(v * ((c-l)-(h-c))/(h-l), 4, 2)
```

**它在问：** 最近11天的量价形态，比最近4天强还是弱？

**拆解：**
- `((c-l)-(h-c))/(h-l)` = 收盘在区间中的位置 [-1, +1]，+1=收在最高点
- 乘上 volume = 成交量加权后的收盘位置
- 11天SMA - 4天SMA = 慢线-快线，差值 > 0 说明形态在改善

**含义：** 两个时间窗口的SMA差值 = 形态趋势方向。>0对应慢线在快线上方（类似MACD金叉），说明量价结构在变好。它不是找具体什么形态，而是判断**形态趋势的方向**。

**缠论映射：** 等价于笔的力度在增强还是减弱。三买信号中此因子向上 → 离开段大概率有力度。

**数据需求：** open, high, low, close, volume 五列。

## 因子 3: gtja191_054 — 波动率形态+反转提示

**IC=0.0272, IR=0.1606**

```
公式: -1 * rank(ts_std(abs(close-open), 10) + (close-open) + ts_corr(close, open, 10))
```

**它在问：** 开盘收盘之间的关系是否异常到了可能反转的程度？

**拆解：**
1. `ts_std(abs(close-open), 10)` = 最近10天开收盘差的波动率（越大越不稳定）
2. `close - open` = 当天涨跌幅（正=阳线）
3. `ts_corr(close, open, 10)` = 开盘价和收盘价在10天内的相关性（正=同向波动）

三者相加 → rank（百分位排名）→ 乘-1。三项同时大时，因子值变得极负。

**含义：** 高波动率 + 大涨 + 开收盘高度同向 → 因子极负 → 提示警惕回调。捕捉的是"涨得太顺了要小心"。

**缠论映射：** 等价于力度是否衰竭的判断。一笔向上力度大且持续多日 → 该因子提示警告。三买出现后该因子值在下降 → 上涨有持续性；在上升 → 注意变盘。

**数据需求：** close, open 两列即可。

## 因子 4: gtja191_002 — 日内位置变化

**IC=0.0262, IR=0.1619**

```
公式: -1 * delta(((close-low)-(high-close))/(high-low), 1)
```

**它在问：** 和昨天比，今天收盘在K线区间中的位置发生了什么变化？

**拆解：**
- `((close-low)-(high-close))/(high-low)` = 收盘位置指标，范围[-1, +1]
  - +1 = 收在最高点
  - -1 = 收在最低点
  - 0 = 收在正中间
- `delta(..., 1)` = 今天值 - 昨天值
- 乘-1反向

**含义：** 昨天收在高位、今天收在低位 → 因子值变大。这是个短期反转信号——前一天强势后一天走弱时提示反向机会。

**缠论映射：** 等价于检测昨天和今天是否形成包含关系、是否在构成分型。因子值突然变大 → 顶分型可能正在形成。

**数据需求：** close, high, low 三列即可。

## 四个因子的互补性

```
                时序窗口短（1天）             时序窗口长（10-11天）
                 
微观结构信号   │  gtja191_002  (IC=0.0262)  │  gtja191_171  (IC=0.0432)
（K线形态）     │  日内位置变化                  │  开盘收盘不对称性                │
                │                              │                                 │
量价结合信号   │  gtja191_054  (IC=0.0272)  │  gtja191_111  (IC=0.0349)
（量+价）      │  波动率形态（+反转提示）        │  量价形态趋势方向                │
```

四维度覆盖：短时序/长时序 × 纯形态/量价结合，IC相关性低 → 聚合排名更稳定。

## 关于截面排名的理解

alpha_score = rank(因子值, across all stocks)

这意味着：
- **单只股票无法独立计算 alpha_score** — 必须同时有 N 只股票才能做 cross-sectional rank
- **选股场景**（A500候选股筛选）：可用，所有候选股同时计算
- **单只个股诊断**（基本面深度分析）：不可用，退回到原有的 3D 评分(tech+fund+news)
