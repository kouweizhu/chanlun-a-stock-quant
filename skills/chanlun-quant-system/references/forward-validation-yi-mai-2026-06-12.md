# P0-5: 一卖/一买 Forward Validation 缺失

## 发现时间
2026-06-12，分析中国中免(601888)时由用户指出。

## 问题描述

`_find_first_class_points()` 在识别一卖（趋势背驰）后，**未检查一卖之后的价格是否创出了新高**。当系统在前一个"趋势"的末尾标记一卖后，如果价格继续上涨并形成更高位的中枢，该一卖实际上不是真正的趋势终点，但系统仍将其保留并用于后续的二卖判定、否决决策等。

### 问题代码位置

`generate_analysis.py`，`_find_first_class_points()` 方法（约 L536-L745，修复前）。

### 具体案例：中国中免(601888) 2025-09-18

| 事件 | 日期 | 价格 | 说明 |
|:-----|:----:|:----:|:------|
| 系统标记一卖 | 2025-09-18 | 74.06 | "上涨趋势背驰（面积:6.98>1.55）"，置信度4 |
| 后续最高价 | 2026-01-20 | **99.81** | 远高于一卖价 74.06 |
| 派生二卖 | 2026-06-05 | 60.26 | 系统以74.06为参照标记"一卖后反弹不创新高" |

**缠论铁律**（《教你炒股票》第24课）：一卖必须是上涨趋势的最终终点。**一卖之后如果价格创出新高，说明原"一卖"只是中枢震荡中的次要高点，真正的顶在后面，该一卖无效。**

中国中免的一卖@74.06后价格涨到99.81，直接违反了这条铁律。该一卖是假的，以它为参照的派生二卖也是假的。

## 根因分析

### 现有检查的不足

`_find_first_class_points()` 中有两个结构性检查，但都只**向后看**（backward-looking），缺少**向前看**（forward-looking）的验证：

| 检查 | 方向 | 逻辑 | 覆盖场景 |
|:----|:----:|:-----|:---------|
| `counter_trend` | 向后 | 检查最后一个中枢之后是否有更低的新中枢 | 某趋势是否已被反向趋势终结 |
| `_check_first_sell_structure()` | 向后 | 检查首次升破ZG后是否有回调跌破ZD | 上涨结构是否已被反向走势破坏 |
| **❌ Forward validation（缺失）** | **向前** | **检查一卖之后是否有更高价格的向上一笔** | **一卖是否被后续价格突破** |

`_check_first_sell_structure()` 检查的是"在离开段形成之前，结构是否已被破坏"——即首次升破ZG后有一个向下笔跌破了中枢下沿ZD。但中国中免的案例中，结构从未被"破坏"（没有跌回ZD），只是离开段形成后再上涨到了更高位置。

### 为什么 counter_trend 也没能阻止

counter_trend 检查的是：最后一个中枢**之后**是否有更低的中枢。中国中免的案例中，一卖之后形成的是**更高**的中枢（ZD=87.17），不是更低的中枢，所以 counter_trend 检查没有触发。

## 修复方案

### 修复位置

`generate_analysis.py`，`_find_first_class_points()` 方法末尾，`return points` 之前。

### 核心逻辑

**Forward validation（前向验证）**：一卖之后，如果365日内存在任意向上一笔的终点价 > 一卖价格，则该一卖无效，从列表中移除。

**365日窗口的合理性**：超过1年后出现的新高应视为独立的新趋势周期，不应破坏前一个趋势周期的一卖。

### 修复代码

```python
# 在 _find_first_class_points() 末尾，return points 之前

validated = []
for point in points:
    invalidated = False
    point_dt = parse_date_to_datetime(point.date)
    
    if point.type == 'sell' and point.level == 1:
        # 一卖：检查后续是否有更高价格的向上一笔
        for bi in self.bis:
            if bi.direction != 'up':
                continue
            bi_dt = parse_date_to_datetime(bi.end_date)
            if bi_dt <= point_dt:
                continue
            if (bi_dt - point_dt).days > 365:
                break  # 超过1年视为新周期
            bi_high = max(bi.start_price, bi.end_price)
            if bi_high > point.price:
                invalidated = True
                break
    
    elif point.type == 'buy' and point.level == 1:
        # 对称：一买后是否有更低价格的向下一笔
        for bi in self.bis:
            if bi.direction != 'down':
                continue
            bi_dt = parse_date_to_datetime(bi.end_date)
            if bi_dt <= point_dt:
                continue
            if (bi_dt - point_dt).days > 365:
                break
            bi_low = min(bi.start_price, bi.end_price)
            if bi_low < point.price:
                invalidated = True
                break
    
    if not invalidated:
        validated.append(point)

return validated
```

### 检查优先级

由于此修复发生在 `_find_first_class_points()` 末尾，它在 `_find_second_class_points()` 之前执行。因此：
1. 假一卖被移除 → `first_class_points` 传入 `_find_second_class_points` 时已不含假一卖
2. 派生二卖自动消失（因为没有一卖可参照）

**不需要单独的二卖前向验证。** 二卖的有效性完全取决于参照一卖的有效性。

## 与已有机制的关系

| 机制 | 作用 | 与 Forward Validation 的关系 |
|:-----|:-----|:----------------------------|
| `counter_trend` | 检查最后一个中枢后是否有反向趋势 | **互补**：counter_trend 看中枢层面，forward validation 看笔层面 |
| `_check_first_sell_structure()` | 检查趋势结构是否被反向破坏 | **互补**：结构检查看一卖形成前，forward validation 看一卖形成后 |
| 买卖点信号有效性校验（stock-analysis v5.3） | Agent 手动验证一卖有效性 | **升级为算法自动验证**，不再依赖人工检查 |

## 影响范围

- **P0级**：影响所有缠论分析中涉及一卖/二卖信号的使用
- **直接后果修复**：
  - 假一卖不再参与否决机制（"日线顶背驰+一卖→降级2档"不会因假一卖错误触发）
  - 假二卖不再被派生（节省分析噪声）
  - 以假一卖为参照的顶部背驰评分不产生错误扣分
- **非影响**：三类买卖点不受此修复影响（它们不依赖一卖/一买）

## 理论依据

缠论买卖点定义（《教你炒股票》原文）：

> **第一类买点**：在某级别趋势中，最后一个中枢的第三类买点出现后，趋势背驰产生第一类买点。
> **第二类买点**：在第一类买点之后，第一次次级别回调不创新低，即为第二类买点。
> **第三类买点**：离开最后一个中枢后，第一次次级别回调不进中枢，即为第三类买点。

> **第一类卖点**：在某级别趋势中，最后一个中枢的第三类卖点出现后，趋势背驰产生第一类卖点。
> **第二类卖点**：在第一类卖点之后，第一次次级别反弹不创新高，即为第二类卖点。
> **第三类卖点**：离开最后一个中枢后，第一次次级别反弹不进中枢，即为第三类卖点。

一卖的"上涨趋势背驰"隐含的前提是：该趋势确实**已经结束**。如果一卖后价格创出新高，证明该趋势尚未结束，一卖判定不成立。这是[趋势背驰]定义本身的逻辑推论，而非额外的约束条件。
