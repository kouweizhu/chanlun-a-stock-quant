# 二买稀少的原因分析

## 现象

A500全量扫描（510只）中，二买仅1只（赛力斯601127），而一买21只、三买345只。
Phase2候选（score≥3）中：二买1只，一买20只。

## 三层原因

### 原因一：时间窗口限制（主因）

二买需要「**一买 → 反弹笔 → 回调笔**」完整结构才能形成。

日线级别笔的形成条件：
- 至少5根合并K线
- 顶底分型交替确认
- 通常需要 **2-4周** 才能形成一根有效笔

二买结构最短也需 **4-8周**（反弹笔 + 回调笔）：

```
一买@T
    │
    ├── 反弹笔（↑）: 2-4周
    ├── 回调笔（↓）: 2-4周
    │
    └── 二买 @T+4~8周
```

但Phase 1扫描到的一买全部是近期的（0-16天前）：

| 天数范围 | 一买数量 | 典型股票 |
|:--------:|:--------:|----------|
| 0-5天 | 8只 | 通威、浦发、春秋、恒瑞 |
| 5-10天 | 2只 | 华菱钢铁、京沪高铁 |
| 10-16天 | 8只 | 分众、同仁堂、中国中车 |
| 16-19天 | 2只 | 中国中冶 |

平均~10天，远不够形成反弹+回调的双笔结构。

### 原因二：笔的形成门槛

即使一买距今天数较长（如中国中冶，一买@04-24，距今19天），一买后的价格波动也可能不足以形成新笔：

```
中国中冶(601618) 一买@2026-04-24 ¥2.89
↓ 04-15→04-24  ¥3.01→¥2.89  ← 一买
  04-24→05-13  横盘震荡        ← 未形成有效笔
```

笔的生成条件：
1. 顶分型→底分型（或反之）的交替出现
2. 分型之间至少 `min_bi_klines`（默认5）根合并K线
3. 底分型低点 < 顶分型高点（向上笔）或反向（向下笔）

小幅震荡行情下，即使过了一两周也不一定形成完整笔。

### 原因三：远期二买评分低（已修复 v3.5.3）

**原问题**：pool_scanner.py 对所有买点类型统一使用30天窗口，>30天→score=2，低于Phase2门槛（≥3分）。二买天然滞后一买4-8周，该规则使二买永远无法进入Phase2候选。

**修复（2026-05-14）**：在标准买点评分循环中，对二买单独放宽到60天：

```python
if days_ago <= BUY_WINDOW_RECENT:
    score = 5
    recency = "近期"
elif bp.level == 2 and days_ago <= BUY_WINDOW_RECENT * 2:
    # 二买：31-60天也给4分
    score = 4
    recency = "中期"
else:
    score = 2
    recency = "远期"
```

**影响**：当前二买数量仍为1只（因一买太近期），但等2-4周后现有20个一买形成完整结构，预计有5-15个二买进入候选。

## 赛力斯的正面案例

唯一被检测到的二买 **赛力斯(601127)**：

```
一买@2026-04-07 ¥85.55，二买@2026-05-13 ¥85.02
                                    ↓ 耗时36天
↓ 03-17→04-07  ¥105.30→¥85.55   一买（MACD背驰）
↑ 04-07→04-23  ¥85.55→¥95.94   反弹笔
↓ 04-23→05-13  ¥95.94→¥85.02   回调笔（低点85.02 ≥ 一买84.69）
                                    → 二买成立 ✅
```

触发条件：
1. 一买后有清晰的两笔结构（向上+向下）
2. 回调低点不创新低（85.02 ≥ 85.55 × 99% = 84.69）✅
3. 36天一买→二买周期，属于"中期"二买（31-60天），在新的60天窗口内

### 二买检测的时间线

```
一买 @T=0            反弹笔              回调笔              二买检测
  │───────────────────┬───────────────────┬────────
  0                  15                  35         40+ (天)
                      ↑ 向上笔完成        ↑ 回调笔低点确认
                                         = 二买生成
```

**关键**：二买在**回调笔的终点**生成（回调笔结束日），该日期往往离一买4-8周。所以二买的日期本身可能是"近期"或"中期"的，即使产生它的一买是远期的。

### ⚠️ 赛力斯型假二买：回调笔终点无分型确认

**问题**：`_find_second_class_points()` 取 `callback_bi.end_date` 作为二买日期。当末笔被延伸时（`_extend_last_bi` 将最新K线纳入笔中而不需要新分型），该日期不一定是真正确认的笔终点。

**赛力斯(601127) 完整时间线**：

```
K线数据（2026-05-13前）：
┌────────────┬───────┬───────┬───────┬───────┬────────┐
│   日期      │ 开盘   │ 最高   │ 最低   │ 收盘   │ 分型    │
├────────────┼───────┼───────┼───────┼───────┼────────┤
│ 2026-05-06 │ 87.00 │ 88.48 │ 87.00 │ 88.07 │ 🔻底   │ ← 真正回调结束
│ 2026-05-07 │ 88.00 │ 89.48 │ 87.88 │ 89.19 │        │
│ 2026-05-08 │ 89.07 │ 92.90 │ 88.18 │ 90.30 │ 🔺顶   │ ← 反弹
│ 2026-05-11 │ 89.85 │ 89.87 │ 88.90 │ 89.19 │        │
│ 2026-05-12 │ 89.02 │ 89.10 │ 86.61 │ 86.75 │        │
│ 2026-05-13 │ 86.55 │ 88.73 │ 85.02 │ 87.46 │        │ ← 无分型 ⚠️
└────────────┴───────┴───────┴───────┴───────┴────────┘

修复前：二买 @2026-05-13 ¥85.02  ⚠️ 无底分型
修复后：二买 @2026-05-06 ¥87.0   ✅ 底分型确认
```

**修复方案**（v3.5.3，2026-05-14）：

```python
# 在二买/二卖生成前，检查回调笔终点是否有分型确认
# 对延伸中的笔，回溯到区间内的最后一个有效分型
_end_date = callback_bi.end_date
_end_price = callback_bi.end_price
if callback_bi.direction == 'down':
    _end_has_bottom = any(str(fx.date)[:10] == str(callback_bi.end_date)[:10] 
                          and fx.type == 'bottom' for fx in self.fenxings)
    if not _end_has_bottom:
        # 笔被延伸，找区间内最后一个底分型
        _last_bottom = None
        for fx in reversed(self.fenxings):
            if fx.type == 'bottom' \
               and str(fx.date)[:10] <= str(callback_bi.end_date)[:10] \
               and str(fx.date)[:10] >= str(callback_bi.start_date)[:10]:
                _last_bottom = fx
                break
        if _last_bottom:
            _end_date = _last_bottom.date
            _end_price = _last_bottom.price
        else:
            continue  # 找不到底分型，不产生二买
```

**对称修复**：二卖的反弹笔终点检查顶分型。

**改动文件**：`generate_analysis.py:_find_second_class_points()`

### 笔终点分型确认的通用影响

- 一买/一卖：`_find_first_class_points()` 取 `leave_bi.end_date`，这些笔通常有底分型（一买）或顶分型（一卖）确认，因为背驰点天然是分型点。未发现延伸导致的一买/一卖误标案例。
- 二买/二卖：上述赛力斯案例证实存在延伸导致误标。因二买的回调笔可能处于延伸中，检查分型是必要的。
- 三买/三卖：由类买卖点逻辑生成，基于笔的突破/回踩，未发现延伸问题。

## 二买 vs 一买 vs 三买的出现频率

| 买点类型 | 理论频率 | 形成周期 | 全部510只中 | 候选(≥3)中 |
|:-------:|:--------:|:--------:|:----------:|:----------:|
| **三买** | 最高 | 每次中枢突破后回踩都可能 | 345只 | 14只 |
| **一买** | 中等 | 每个下跌趋势末端的背驰点 | 21只 | 20只 |
| **二买** | 最低 | 一买后还需4-8周 | 1只 | 1只 |

三买多是因为每个中枢的每个突破都可能产生；一买只出现在趋势末端；二买最少——既依赖一买先出现，又需要足够时间形成完整回调结构。
