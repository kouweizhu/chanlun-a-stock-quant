# 缠论信号质量评估框架

## 用途

当系统输出一个买点信号（尤其是 **潜一买(confirmed=False)**），使用本框架评估其合理性与实操价值。信号在系统层面可能"逻辑正确"但"实操过早"——本框架解决这个 gap。

---

## 第一步：趋势结构完整性

### 单中枢 vs 双中枢下跌

- **双中枢下跌**：结构更完整，背驰更可靠。离开下位中枢的笔与进入下位中枢的笔构成正确背驰对照对。
- **单中枢下跌**：结构可能尚未完成，离开中枢的笔背驰可能是"中枢扩展"或"趋势中继"，不是真正的趋势背驰。

**评估规则：**
| 中枢数量 | 信号可靠性 | 说明 |
|----------|:---------:|------|
| 2+ 个中枢 | ★★★★ | 趋势完整，背驰对照对明确 |
| 1 个中枢 | ★★ | 可能只是盘整背驰，非趋势背驰 |

### 进入笔与离开笔是否符合背驰对照逻辑

潜一买的核心是"离开最后一个中枢的笔"与"进入最后一个中枢的笔"之间的面积/力度背驰。

- 进入笔 = 形成中枢之前的那笔（向下离开前一个中枢的方向）
- 离开笔 = 跌破中枢后的那笔（向下离开中枢）
- **正确对照对**：进入笔 → 离开笔 （必须有"向上回到中枢"的笔在中间形成完整结构）

> **检查要点**：系统标记的 break_before_area（进入段面积）和 break_after_area（离开段面积）是否确实分别是"进入该中枢"和"离开该中枢"的两笔，而不是中枢内部的同向笔。

---

## 第二步：三卖风险排除

### 核心判断：价格 vs ZD

这是潜一买评估中最关键的一步。跌破中枢后的信号，首先要问的不是"这是一买吗"，而是"这是三卖吗"。

**定义：**
- **ZD（中枢下沿）** = 中枢区间下沿
- 价格跌破 ZD = 中枢破坏
- 若价格反弹后 **无法回到 ZD 以上** = 三卖确认

**风险矩阵：**

| 状态 | 含义 | 信号建议 |
|------|------|---------|
| 价格刚跌破 ZD（<3 根 K 线）| 信号过早，趋势未耗尽 | ❌ 等待 |
| 价格在 ZD 下方横盘（5-10 根 K 线）| 可能形成底部，也可能继续下跌 | ⚠️ 观察 |
| 价格反弹回到 ZD 以上 | 假跌破（向下笔被打断）| ✅ 潜一买可信度大幅提升 |
| 价格反弹但被 ZD 压制回落 | 三卖确认（反弹不进中枢）| ❌ 潜一买失效，转三卖评估 |
| 价格在 ZD 下方二次背驰 | 高胜率一买 | ✅✅ 最强信号 |

### 线段级别上下文

检查该下跌线段是否构成对一个更大级别上涨趋势的修正：

- 如果当前下跌段 **未跌破** 前一个上涨段的起点 → 整体上升趋势未破坏，当前只是回调修正（二买或类二买范围，非一买）
- 如果当前下跌段 **跌破** 前一个上涨段的所有反弹高点 → 趋势反转确认，背驰信号更可信

---

## 第三步：缺口与急跌排除

缠论原文强调：**急跌段不能用背驰处理**。

**检查要点：**
- 离开中枢的笔是否包含跳空缺口（日线级别）
- 是否出现连续 3 根以上跌停/大阴线
- 是否为政策突发事件导致

如果存在急跌/缺口，要求至少等一个完整的底分型确认后再评估信号。

---

## 第四步：多级别共振确认

| 维度 | 加分条件 | 评分 |
|------|---------|:----:|
| 30F 笔背驰 | 30分钟 K 线数据中也有 MACD 面积背驰 | +1 |
| 成交量 | 最后一跌缩量（低于前笔均量的 70%）| +1 |
| RSI 超卖 | 日线 RSI < 30 | +0.5 |
| 筹码支撑 | 下方有筹码峰（成本集中区）| +0.5 |
| 分笔背驰 | 1分钟/5分钟 K 线已有分笔底背驰 | +0.5 |

得分 ≥ 3 → 可信度较高  
得分 2-3 → 中等可信，需额外谨慎  
得分 < 2 → 不建议作为交易依据

---

## 第五步：实操优先级矩阵

| 信号特征（多条件组合） | 建议 |
|------------------------|------|
| 双中枢下跌 + 离开笔面积缩减>30% + 价格已横盘>5K线 | 可小仓试多，止损设最近低点下方 0.5% |
| 双中枢下跌 + 面积背驰 + 价格刚破 ZD（当日）| 等待，不追 |
| 双中枢下跌 + 面积背驰 + 已回到 ZD 上方 | 结构修复，确认假跌破——可积极关注，等待回调至 ZD 附近不破再接 |
| 单中枢下跌 + 任何条件 | 谨慎，优先看盘整背驰、类二买而不是一买 |
| 任何条件 + 三卖风险未排除（反弹不过 ZD）| 不做一买，评估三卖机会 |
| 下跌+背驰+二次背驰（新低后再次背驰）| 高胜率，可重仓，但需确认第二次背驰的 MACD 面积 < 第一次背驰 |

---

## 常见陷阱

1. **"系统出信号=可以买"**：潜一买是系统的最低置信标记，明确标注 confirmed=False。系统标记它是为了"标记需要关注的标的"，不是"建议立刻买入"。

2. **"面积越小背驰越强"**：MACD 面积缩减只是条件之一。还要看：该笔的持续时间和幅度是否匹配——一笔极度压缩的小阴线快速结束，可能不是背驰而是"空方衰竭"的信号，结构上更可靠。

3. **"中枢跌破就必须走"**：中枢跌破 ≠ 趋势走坏。关键是看跌破后的回抽力度。快速收回 ZD 的下跌是"多头陷阱"的失败。

4. **"三卖和一买是互斥的"**：不互斥。三卖确认（反弹不过 ZD）之后如果再次新低并背驰，是更高胜率的买点（二次背驰后的标准一买）。三卖不是交易的终点，它只是淘汰了当前中枢内的机会，打开了下一段下行段背驰的空间。
