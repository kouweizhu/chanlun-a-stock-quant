# 线段中枢测试报告 (2026-05-02)

## 背景

用户提出：笔中枢是否可以用线段中枢替代，以获得更高的可靠性和稳定性？

### 理论对比

| 维度 | 笔中枢 | 线段中枢 |
|------|--------|---------|
| 构成 | 3笔重叠 | 3段重叠（≥9笔确认） |
| 级别 | 低 | 高 |
| 灵敏度 | 高（信号多、噪音多） | 低（信号少、质量高） |
| 假突破 | 容易被短期波动穿透 | 边界更"厚实" |
| 背驰判断 | 可信度一般 | 可信度高 |

### 完整实现的工程复杂度

线段的严格划分涉及：
1. **特征序列提取**：从笔中提取顶/底分型序列
2. **包含处理**：特征序列中相邻元素的包含关系（方向不同规则不同）
3. **线段破坏判断**：第一种破坏（直接突破）vs 第二种破坏（特征序列缺口）
4. **边界情况爆炸**：组合起来的边界情况数量指数级

缠论原文在某些边界情况的描述上存在歧义，不同人理解不同。

## 简化版方案

跳过特征序列、包含处理、破坏判断，用"3笔成段"规则：

```
连续3笔（上下上 或 下上下）构成一个线段
线段确定后跳过整个线段（避免重叠碎片化）
线段中枢 = 3个连续线段的重叠区间
```

## 结论

1. 线段中枢数量从 5 降到 2，过滤效果明显
2. 线段中枢更"厚实"，平均宽度更大
3. 002415 日线在 2025 年实际只有两个大结构：上半年 26-28 箱体，下半年 29-33 箱体
4. 简化版（3笔成段）已能体现线段中枢的优势，无需完整特征序列实现
