# 三买检测误判复盘：闭笔可以作为突破笔

## 场景

分析兆易创新(603986)三买信号时，发现系统在三买检测中把中枢闭笔作为向上突破笔（`b.end_date >= zs.end_date`）。初步推断这是一个 bug，提出改为 `b.start_date > zs.end_date`。

## 错误分析链条

```
中枢#5 [2025-09-09~2026-01-28] ZG=231
笔[38] up 12/17→01/28  high=330 > ZG=231 → UP BREAK ← 同时是中枢闭笔
笔[39] down 01/28→02/05 low=267 > ZG=231 → PULLBACK ✓
笔[40] up 02/05→02/24                → ★ 三买 @ 02-05 ¥267.81
```

**错误判断**：笔[38]是中枢的最后一笔（end_date=01-28 = zs.end_date），不应被当作突破笔。认为需要"中枢完成后第一个明确在中枢外的向上笔"。

## 用户纠正

> 三买的核心是"离开中枢后回抽不破ZG（中枢上沿）"
>
> 三买形成条件：在最后一个下跌中枢完成后，出现次级别及以上向上离开中枢的走势（未必是"第一笔"，但需构成有效离开段），随后回抽确认时低点不跌破中枢上沿（ZG），即构成第三类买点。
>
> 理解了吗？

**要点**：
1. 闭笔作为向上离开段是缠论允许的——**不需要"第一个在中枢外"的笔**
2. 三买只有两个条件：① 有向上段离开中枢（突破ZG）；② 回抽不破ZG
3. 闭笔是否"中枢的一部分"不重要——重要的是它确实突破了ZG，且回抽确认没进来
4. 同一个中枢可以有多个三买（每次突破后回抽不破ZG都构成一个新三买）
5. 越后面的三买价格越低（回抽越深），性价比可能越高

## 确认结果

受检的5个三买（兆易创新、华工科技、麦格米特×3）中4个有效：
- 兆易创新 2026-02-05 ✅ 闭笔离开段，回抽确认
- 华工科技 2026-04-02 ✅ 同上
- 麦格米特 2025-09-09 ✅ 同上
- 麦格米特 2026-02-11 ✅ 同上
- 麦格米特 2026-01-05 ⚠️ 结构成立，但引用的是9个月前的中枢#2，应以最近中枢#4为准（回抽进入#4）

## 经验教训

| 误区 | 正确理解 |
|:----|:--------|
| 认为闭笔不能同时做突破笔 | 闭笔可以作为离开段，核心是离开的有效性 |
| 认为中枢完成后才可突破 | 中枢的最后一笔完成向上突破是缠论允许的正常结构 |
| 认为`>=`过滤太松是bug | `b.end_date >= zs.end_date` 是对的——闭笔的end_date本就和zs.end_date相等 |
| 误提议改为`>` | 改为`b.start_date > zs.end_date`会导致大量有效三买漏检 |

**最终结论**：系统中 `_find_buy_sell_points()` 的 `after_bis = [b for b in self.bis if b.end_date >= zs.end_date]` **不需要修改**。三买的正确性由"回抽不破ZG"保证，不由突破笔是否闭笔决定。
