# 底背驰段比较方法论 — 必须比较「离开段 vs 离开段」

## 核心原则

底背驰（背离）比较的两个段必须是**同级别、同性质的线段**——具体来说，是两个同向的**离开段（离开中枢的段）**，而不是中枢内部的笔。

## 常见错误

### ❌ 错误：中枢内笔 vs 离开段（2026-06-10 中国人寿案例）

```
中枢B [04-07~05-11]: ZG=38.31, ZD=36.10

笔序列:
  04-07→04-15 ↑ (35.51→38.31)   ← 回抽进入中枢构成三卖
  04-15→04-24 ↓ (38.31→36.10)   ← 中枢内笔(ZG→ZD) ❌ 不是离开段
  04-24→05-11 ↑ (36.10→38.60)   ← 中枢内笔
  05-11→06-04 ↓ (38.60→32.32)   ← 离开段(跌破ZD)
```

初次分析比较了 `04-15→04-24` (面积5.2159) 与 `05-11→06-04` (面积5.1926) → **99.55% → 误判为无背驰**

### ✅ 正确：离开段 vs 离开段

```
中枢A [01-30~04-07]: ZG=43.45, ZD=41.21
  离开段A: 03-17→04-07 ↓ (43.45→35.51) 跌破ZD → 面积6.7470

中枢B [04-07~05-11]: ZG=38.31, ZD=36.10
  离开段B: 05-11→06-04 ↓ (38.60→32.32) 跌破ZD → 面积5.1926
```

比较 **离开段B vs 离开段A** → **76.96%** → 虽然尚未达标(需≤70%)，但已是有意义的衰减

## 缠论理论依据

底背驰比较的正确对象取决于当前趋势结构：

| 趋势结构 | 比较对象 | 说明 |
|:---------|:---------|:-----|
| **单中枢下跌** | 进入段 vs 离开段 | 进入中枢的下跌段 vs 离开中枢的下跌段 |
| **双中枢趋势** | 第二个中枢的离开段 vs 第一个中枢的离开段 | 两个离开段比较，中间夹一个中枢 |
| **中枢扩展/延伸** | 最近两个离开段 | 若有多个中枢，比较最后两个离开段 |

### 判别规则

1. **离开段的定义**：一笔的完整价格区间包含整个中枢区间（高点≥ZG **且** 低点≤ZD），即"穿透笔"——见 `references/zhongshu-extension-bug-2026-06-01.md`
2. **内部笔**：价格在中枢区间内波动（高点≤ZG 或 低点≥ZD，但不满足穿透条件），**不参与底背驰比较**
3. **趋势完整性**：确认趋势中有至少一个中枢（单中枢）或两个中枢（趋势）

## 验证方法

当对两个段进行底背驰比较时，先做以下检查：

```
□ 段A的端点是否完全包含某个中枢区间？（高点≥ZG且低点≤ZD）
   → 是 → 段A是离开段 ✓
   → 否 → 段A是中枢内部波动 ❌ 不能参与比较

□ 段B的端点是否完全包含某个中枢区间？
   → 是 → 段B是离开段 ✓
   → 否 → 段B是中枢内部波动 ❌ 不能参与比较

□ 段A和段B是否同向（同为下跌段或同为上涨段）？
   → 是 → 可以比较 ✓
   → 否 → 方向不一致 ❌ 不能比较

□ 段A和段B是否从不同的中枢离开？（中间至少隔一个完整中枢）
   → 双中枢趋势比较 ✓
   → 单中枢趋势：比较进入段和离开段 ✓
```

## 参数设置

在 `generate_analysis.py` 中，底背驰阈值为 `divergence_threshold = 0.7`（v4.0从1.0降至0.7）：

| 面积比 | 结论 | 代码动作 |
|:------:|:-----|:---------|
| ≤70% | ✅ 底背驰成立 | 技术评分加分 |
| 70%~85% | ⚠️ 底背驰雏形 | 标注但不加分，需等待二次验证 |
| >85% | ❌ 无背驰 | 不触发 |

**注意**：该阈值仅用于自动化系统的保守过滤。缠论原文中，底背驰的判断标准是MACD柱面积**明确小于**前一段（非特定数值）。当面积比在70%-85%之间时，建议在报告中标注为"雏形背驰"而非直接忽略。
