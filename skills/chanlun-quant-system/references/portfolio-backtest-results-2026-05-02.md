# 组合回测结果：慢牛 2016.06-2017.11

> 日期: 2026-05-02 | 脚本: `portfolio_backtest.py` | 股票池: 50只 A500 老票

## 核心结论

**单只回测的"系统不适配慢牛"结论是错的。** 问题不在系统，在回测方式。

单只回测每只股票独立分配 ¥200 万但单股最大仓位仅 18%（¥36 万），82% 资金永远闲置。
组合回测共享资金池、80% 仓位目标后：+61.40%，碾压沪深 300 的 +26.75%。

## 关键发现

1. **止盈放宽（tp=1.67）在组合模式中反而有害**：收益从 61.40% 降到 40.35%。持仓变长→资金周转变慢→复利效应减弱。默认 15% 止盈（快速轮动）才是最优。

2. **系统真实 Alpha = +34.65%**（组合 - HS300），远超预期。

3. **风控极优**：基准组最大回撤仅 3.63%，胜率 71%，同时持有 6-8 只股票。

4. **买点分布不变**：三买仍占主导（95%+），一买极少。但组合模式下这些"小波段"通过资金复用叠加成了 61% 的总收益。

## 参数

- 初始资金: ¥2,000,000
- 买入阶梯: 9% / 6% / 3%（单股最大 18%）
- 目标仓位: 80%
- 止盈: 15%（默认）/ 25%（tp=1.67）
- 止损: 结构止损 → 硬止损-8%（无 M30 数据，跳过次级别止损）
- 滑点 + 手续费: 已建模
