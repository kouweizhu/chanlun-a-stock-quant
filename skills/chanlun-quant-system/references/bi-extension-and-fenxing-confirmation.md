# 笔延伸与分型确认规则（2026-05-08 补充）

## 一、笔的基本定义
笔是相邻两个顶分型/底分型之间的K线序列：
- **向上笔**：底分型 → 顶分型（低点→高点）
- **向下笔**：顶分型 → 底分型（高点→低点）

## 二、笔的延伸（Extension）条件

### 向上笔延伸中，需要满足：
1. **不出现新的底分型**（否则向下笔开始）
2. **最高价不断刷新**（或至少不破前高）
3. **最后一根K线的高点 ≥ 前高**（笔的延伸方向维持）

⚠️ **常见误解**："不出现顶分型，向上笔就继续" ❌  
✅ **正确**：向上笔延伸中，**不出现底分型**（反向分型）。顶分型可以出现，只要后续K线突破它，笔就继续延伸。

### 向下笔延伸中，需要满足：
1. **不出现新的顶分型**
2. **最低价不断刷新**（或至少不破前低）
3. **最后一根K线低点 ≤ 前低**

## 三、反向笔形成条件（笔的结束）

反向笔开始 = 当前笔结束。

| 当前笔类型 | 反向笔形成条件 | 关键动作 |
|:-----------|:------------------|:--------|
| 向上笔（up） | 出现**底分型** + 底分型中间K线低点 **低于**向上笔的终点（last_bi.end_price） | 顶分型被击穿，向上笔终结 |
| 向下笔（down） | 出现**顶分型** + 顶分型中间K线高点 **高于**向下笔的终点（last_bi.end_price） | 底分型被击穿，向下笔终结 |

### 分型确认（必须）：
- **底分型确认**：后续K线收盘 **跌破底分型中间K线的低点**
- **顶分型确认**：后续K线收盘 **突破顶分型中间K线的高点**

⚠️ **分型出现 ≠ 笔结束**：分型未被确认 = 中继分型，原笔继续。

## 四、中继分型 vs 反转分型

### 中继分型（延续原方向）
- 分型出现后，后续K线**突破**分型中间K线的极值点（底分型突破低点/顶分型突破高点）
- 原笔继续延伸，该分型被"吞没"
- **系统处理**：不应标记反向笔/买卖点

### 反转分型（趋势反转）
- 分型出现后，后续K线**确认**了该分型（收盘跌破/突破）
- 原笔结束，反向笔开始
- **系统处理**：标记反向笔，可能触发买卖点

## 五、沪深300月线实例验证（2026-05-08）

### 真实月线数据（不复权，过滤未闭合5月K线）：
| 月份 | 收盘 | 高点 | 低点 | 分型角色 |
|:-----|:----:|:----:|:----:|:--------|
| 2026-01 | 4706.34 | **4836.95** | 4645 | 可能的顶分型中间 |
| 2026-02 | 4710.65 | 4766.56 | 4578 | 底分型右侧？ |
| **2026-03** | **4450.05** | 4744.60 | **4394.29** | **底分型中间（低点最低）** |
| **2026-04** | **4807.31** | 4829.27 | 4420 | **突破3月高点4744 → 中继底分型确认** |

### 判定结论：
```
底分型结构（2026-02/03/04）：
  K1（2月）：低点4578
  K2（3月）：低点4394 ← 中间最低 ✓
  K3（4月）：低点4420（>4394），但收盘4807 > 3月高点4744
  
结论：K3收盘突破K2高点4744 → 底分型未被确认 → 中继底分型 → 向上笔继续
```

## 六、系统实现注意事项

1. **未闭合K线不参与**：月线/周线等高级别K线需要整周期闭合后才能参与分型、笔、中枢的构建（已记录到Pitfalls）。
2. **笔延伸判断**：检查最后N根K线是否形成新的反向分型，而非简单看价格涨跌。
3. **分型确认延迟**：分型形成后可能需要1-3根K线才完成确认，系统应允许短暂"未确认"状态。
4. **数据验证**：报告中的价格数据必须与数据源交叉验证，避免记忆错误（如本次将~4870误报为真实数据）。

## 七、快速对照表

| 说法 | 对错 | 理由 |
|:-----|:----:|:------|
| "不出现底分型，向上笔就继续" | ✅ 对 | 底分型才是反向笔的开始 |
| "不出现顶分型，向上笔就继续" | ❌ 错 | 顶分型是向上笔的终点，可以出现后继续延伸 |
| "分型出现=笔结束" | ❌ 错 | 必须确认（后续K线突破极值点） |
| "中继分型后原笔继续" | ✅ 对 | 分型未被确认，被后续K线突破 |
| "反转分型后反向笔开始" | ✅ 对 | 分型被确认，原笔终结 |
