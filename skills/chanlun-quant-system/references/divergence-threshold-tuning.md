# 一买参数调优：divergence_threshold 阀值

> 2026-05-29 发现，A500 全量扫描验证

## 背景

在 2026-05-29 的 A500 选股全流程中，用户发现"报告中出现很多股票有一买，但是一买应该是最难出现的"。经批量检查，39 只标记为"一买"的股票中有 9 只背驰比 > 70%，背驰极弱，不应被视为有效趋势背驰。

## 根因

`generate_analysis.py:64`：

```python
divergence_threshold = 1.0  # 默认值
```

该参数用于背驰判断：当 `离开段MACD面积 < 进入段MACD面积 × divergence_threshold` 时判定为背驰。`1.0` 意味着只要离开段面积比进入段面积**任何程度的小**就算背驰——即使仅小 0.1%。

对比缠论原文对趋势背驰的要求："最后一个中枢的离开段比进入段力度明显减弱"——强调 **明显** 二字，1.0 不满足此条件。

## 推荐修改

```python
divergence_threshold = 0.7  # 推荐值
```

即离开段面积 < 进入段面积的 70% 才算背驰。与缠论原文"明显减弱"匹配，且经验证可剔除 9/39 假一买。

### 关键结论

1. 假一买的核心共同特征：**进入段和离开段的笔长相近（2-4周），进入段面积仅略大于离开段**。这表明进入段和离开段都是同一级别小幅波动的一部分，并非大级别趋势的终结
2. 真一买的核心共同特征：**进入段是长周期下降趋势笔（数月），离开段是短周期探底笔（2-4周）**。面积差巨大意味着大级别趋势力竭
3. 距离比指标（进入段K线数 / 离开段K线数）比背驰比更敏感，对弱背驰（>70%）几乎都有距离比 < 2

## 中国太保（601601）详细案例

### 买卖点验证
- **下跌趋势**：中枢[8]（ZG=45.80, ZD=41.60）→ 中枢[9]（ZG=40.16, ZD=37.41），后中枢ZD<前中枢ZG，有效下跌趋势
- **进入段**：笔[50] 02-09→03-09 下 ¥45.80→¥37.41，MACD面积=12.33
- **离开段**：笔[56] 04-30→05-22（末笔延伸至05-28）下 ¥38.46→¥31.61，MACD面积=4.62
- **背驰比**：4.62 / 12.33 = **37.4%** ✅ 有效背驰
- **一买价格**：¥31.61 @ 2026-05-22
- **当前价格**：¥32.02（分析日，高于一买价1.3%）
- **结论**：一买有效，但末笔延伸导致一买日期应为05-28而非05-22。后几日回调（05-28最低¥30.65）属次级别回踩，未跌破一买价满足$31.61，二买正在构建中

### 笔结构（2026年）
```
笔[50]: 02-09→03-09 下 ¥45.80→¥37.41（进入段）
笔[51]: 03-09→03-17 上 ¥37.41→¥41.18
笔[52]: 03-17→03-30 下 ¥41.18→¥36.11
笔[53]: 03-30→04-08 上 ¥36.11→¥40.16
笔[54]: 04-08→04-24 下 ¥40.16→¥35.91
笔[55]: 04-24→04-30 上 ¥35.91→¥38.46
笔[56]: 04-30→05-22 下 ¥38.46→¥31.61（离开段/一买点，末笔延伸至05-28）
```

### 笔延伸导致日期漂移
- 一买 @05-22 系统标记日期 = 笔[56]的 end_date（¥31.61）
- 但笔[56]因末笔延伸机制 end_date 被固定在 05-22，end_price 延伸至 05-28 最低价 ¥30.65
- 实际上一买的最低价出现在 05-28（¥30.65），但系统标记的 buy_point 日期仍是 05-22
- 影响：用户看到一买后"股价创新低"（05-28 < 05-22），但实际上在 05-28 才走到真底
- 建议：一买日期应跟随末笔延伸后的最低价日期，或至少在报告注释中说明

### 需要修改的引用
该常量在 `ChanLunAnalyzer` 类的 `_find_first_class_points()` 方法中被用于背驰判断（`BACK_DIV` → `buy`）和 `_find_first_class_sell_points()`（`TOP_DIV` → `sell`）。不支持由参数传入（硬编码），因此修改后需要重新运行所有分析才能生效。
