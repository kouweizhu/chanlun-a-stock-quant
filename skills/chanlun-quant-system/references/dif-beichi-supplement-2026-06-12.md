# P0-6: DIF极值背驰补充判断

## 发现时间
2026-06-12，同一卖Forward Validation修复会话中，用户问"2025-12~2026-02中枢内没有一卖吗？"后发现的配套漏洞。

## 问题描述

`_find_first_class_points()` 在识别一卖时，仅检查**MACD面积背驰**（`leave_area < enter_area × divergence_threshold`）。但在**加速赶顶**阶段，离开段的MACD柱绝对值反而比进入段更大，导致面积背驰不成立，真实顶部被漏报。

### 经典案例：中国中免(601888) 上涨趋势9

| 项目 | 数据 | 说明 |
|:-----|:-----|:------|
| 进入段 | [2025-08-04~2025-08-26] 63.95→73.07 | MACD面积: **6.16** |
| 离开段 | [2026-01-28~2026-02-11] 87.17→98.72 | MACD面积: **10.66** |
| 面积背驰条件 | 10.66 < 6.16×0.7=4.31? | **❌ 不成立** (离开段面积更大) |
| **全局DIF最高** | **3.590** (2026-01-12) | 在离开段之前达到 |
| **离开段DIF最高** | **1.531** (2026-02-11) | DIF大幅回落 |
| **DIF背驰条件** | 1.531 < 3.590×0.7=2.513? | **✅ 成立** (DIF明显低于全局高点) |

**实际走势**：2026-02-11到2026-05-28，价格从98.72暴跌至54.56。确认这是真正的趋势顶部。

### 根因分析

MACD面积法的局限：DIF线在零轴上方高位时，MACD柱（DIF-DEA差值）的振幅天然更大。加速赶顶阶段价格快速上涨，MACD柱急剧变大，即使相对于前期涨幅已经减速，绝对面积值仍然较大。

缠师原文（第24课）明确指出背驰判断要看**两组信号**：
1. **红绿柱面积**（MACD柱状图面积比较）— 已有
2. **黄白线高度**（DIF/DEA线极值的比较）— 缺失

## 修复方案

### 修复位置
`generate_analysis.py`，`_find_first_class_points()` 方法中，面积背驰判断处。

### 核心逻辑

在面积背驰比较的同位置，增加DIF极值背驰的补充计算：

```python
# 新增：计算趋势全局DIF最高点（从进入段到离开段之间）
global_dif_max = -999.0
for md in self.macd_data:
    if md.date >= enter_bi.start_date and md.date <= leave_bi.end_date:
        if md.dif > global_dif_max:
            global_dif_max = md.dif

# 离开段的DIF极值（复用已有 _calculate_macd_dif_extreme_for_bi）
leave_dif_max = self._calculate_macd_dif_extreme_for_bi(leave_bi, self.macd_data)

# 面积背驰 OR DIF背驰，满足其一即产生一卖
area_beichi = leave_area < enter_area * self.divergence_threshold   # 0.7
dif_beichi = leave_dif_max < global_dif_max * self.divergence_threshold  # 0.7

if area_beichi or dif_beichi:
    # 一卖成立
```

### 全局DIF vs 进入段DIF的区别

| 方法 | 比较对象 | 效果 |
|:-----|:---------|:-----|
| 进入段DIF | 仅进入段的DIF最高点 | ❌ 进入段DIF可能很低，离开段DIF自然更高，无法判别背驰 |
| **全局DIF** | 整个趋势范围的DIF最高点 | ✅ 如果趋势中途DIF已很高，离开段加速时DIF未创新高，DIF背驰成立 |

DIF极值背驰的力学含义：DIF是趋势动能的度量。全局DIF最高点代表**动能峰值**，离开段DIF未创新高意味**动能衰减**，即使价格加速创出新高，这种上涨是"强弩之末"。

## 与已有机制的关系

| 机制 | 关系 |
|:-----|:-----|
| 面积背驰 | **并行条件**：area_beichi OR dif_beichi，满足其一即产生一卖 |
| Forward Validation | **时序互补**：DIF背驰在前瞻捕捉顶部，Forward Validation在后清除假信号 |
| divergence_threshold | 两处使用**同一阈值**0.7，保持判断一致性 |
| 一买对称 | 一买侧暂未增加DIF底背驰判断（因一买侧价格跌到负值时DIF也负，处理逻辑不同） |

## 风险点

- **假DIF信号的排除**：有些趋势中DIF可能因分红、除权等因素出现跳跃，但本系统使用前复权数据，DIF曲线连续，此风险可控
- **阈值竞争**：面积背驰阈值0.7向下调整时是否需要同步调整DIF阈值？目前两处共用同一阈值，保持对称。若单独调整需评估影响
