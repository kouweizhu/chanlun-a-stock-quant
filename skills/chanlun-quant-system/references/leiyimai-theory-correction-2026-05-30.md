# 类一买理论修正 2026-05-30

## 问题发现

用户在运行A500选股后发现大量"类一买"信号，担心出现类似同仁堂的走势（持续下跌中反复触发类一买导致越抄越亏）。

## 核心理论问题

**一买的本质**：下跌趋势末端的背驰 → 趋势反转信号

**类一买（盘整底背驰）的本质**：盘整区间内的底背驰 → 盘整区间底部反弹

**错误**：系统将"上涨趋势中的回调"也识别为类一买

### 典型反例：艾力斯(688578)

```
中枢ZD趋势：37→55→75→92→103→89
              ↑ 一路涨了3倍   ↑ 回调14%
```

- 中枢ZD从37涨到103（涨了3倍）
- 最近回调到89（-14%）
- 系统错误地将其识别为"类一买"
- 实际这是**上涨趋势中的正常回调**，不是一买/类一买

### 典型正例：同仁堂(600085)

```
中枢ZD趋势：47→41→35→38→36→33→31→28
              ↑ 持续下跌
```

- 中枢ZD持续下移
- 这是**真正的下跌趋势**
- 类一买信号应该降级处理

## 修复方案

### 1. 增加趋势方向检查（_detect_panbei_divergence）

```python
# 条件⑤：趋势方向检查 — 类一买只在下跌/盘整中触发
zhongshus = analyzer.zhongshus
if len(zhongshus) >= 3:
    lookback = min(5, len(zhongshus))
    trend_zs = zhongshus[-lookback:]
    trend_zd = [float(z.zd) for z in trend_zs]
    # 上涨趋势：ZD上涨超过10%
    if trend_zd[-1] > trend_zd[0] * 1.10:
        return 0, "", None  # 上涨趋势中的回调，不是类一买
```

### 2. 标准买卖点路径的类一买处理（scan_stock）

```python
# v3.5.6: 潜在一买(confirmed=False) → 类一买, 下调1分
if best_buy.level == 1 and not getattr(best_buy, 'confirmed', True):
    # v3.6: 上涨趋势中的类一买应该被过滤
    is_uptrend = False
    if len(analyzer.zhongshus) >= 3:
        lookback = min(5, len(analyzer.zhongshus))
        trend_zs = analyzer.zhongshus[-lookback:]
        trend_zd = [float(z.zd) for z in trend_zs]
        if trend_zd[-1] > trend_zd[0] * 1.10:
            is_uptrend = True
    if is_uptrend:
        best_score = 0  # 上涨趋势中的类一买，降为0
        buy_type_str = "类一买(上涨趋势,无效)"
    else:
        buy_type_str = "类一买"
        best_score = max(1, best_score - 1)
```

### 3. 类一买评分调整

| 场景 | 原评分 | 新评分 | 理由 |
|------|--------|--------|------|
| 盘整中+极强背驰(area≤20%) | 5 | 4 | 盘整背驰可靠性低于趋势背驰 |
| 盘整中+强背驰(area≤30%) | 4 | 3 | 同上 |
| 盘整中+温和背驰(area>30%) | 3 | 2 | 同上 |
| 上涨趋势中的回调 | 5/4/3 | 0 | 不是类一买，直接过滤 |

## 两种"潜在买点"的区别

### 潜一买（generate_analysis.py）
- **定义**：背驰条件满足，但还没有向上一笔确认
- **检测**：一买背驰 + 没有向上笔 → 潜在一买（confirmed=False）
- **处理**：在pool_scanner.py中被标记为"类一买"，评分下调1分
- **理论基础**：缠论一买理论 ✅

### 潜在一买/潜在二买（pool_scanner.py）
- **定义**：基于中枢位置和MACD状态的结构性买点
- **检测**：价格在中枢下沿附近 + MACD改善
- **评分**：score=3
- **理论基础**：不是缠论标准概念，是系统自定义的"结构位置评分" ⚠️

## 判断标准总结

类一买触发条件：
1. 价格条件：第二下跌笔低点 >= 第一笔低点的98%
2. 力度条件：MACD柱面积缩减至40%以下
3. 价量确认：当前价 > 第二下跌笔低点
4. 动量确认：MACD金叉或即将金叉
5. **趋势条件：整体不是上涨趋势（ZD上涨不超过10%）** ← 新增
