# 假一买陷阱 — 三卖后结构破坏案例研究

## 典型案例：沃森生物(300142)

### 现象
系统在 2026-04-24 标注「一买 @¥11.65」，但实际股价处在**宽幅震荡**中，并非下跌趋势末端。

### 结构数据

```
中枢#4 [10.79, 11.51] 2025-01→08
中枢#5 [12.57, 13.56] 2025-08→11  ← 上移
中枢#6 [12.02, 12.37] 2025-11→2026-04  ← 下移
           │
           ├─ 笔#26 ↓ 12.37→10.92  ← 跌破ZD → 三卖@2025-12-01
           ├─ 笔#27 ↑ 10.92→14.65  ← ⚠️ 反弹+34%，远超ZG=12.37
           ├─ 笔#28 ↓ 14.65→11.25
           ├─ 笔#29 ↑ 11.25→13.13  ← 又回ZG之上
           ├─ 笔#30 ↓ 13.13→11.45
           ├─ 笔#31 ↑ 11.45→12.97
           └─ 笔#32 ↓ 12.97→11.65  ← 被标为"一买"
```

### 根因分析

`_find_first_class_points()` 的 **counter_trend 过滤**（v3.1）只检查已形成的中枢是否在更高位置，但沃森笔#27（+34%）虽然大幅反弹回到ZG之上，却没有形成新的中枢（后续笔#28~#32 宽幅震荡无三笔重叠）。counter_trend 为空，过滤失效。

### 缠论理论依据

> 三卖确认最后一个中枢被破坏后，如果出现反弹回到ZG之上，说明下跌结构已被反向走势破坏，不再延续。

不依赖新中枢形成——单笔回到ZG之上即可判定。

---

## 修复迭代（v3.5 → v3.5.1 → v3.5.2）

### v3.5：单笔反弹检查
在 `_find_first_class_points()` 中找到 leave_bi 后插入结构完整性检查，遍历中枢后向上笔，任何突破ZG者判定结构破坏。

**问题**：过于激进——宽幅中枢的小幅波动也被误判。

### v3.5.1：日期范围 + 幅度阈值
1. **搜索范围限制**：`first_break` 搜索加 `bi.end_date >= zs.start_date` 跳过中枢前笔
2. **幅度阈值**：`min_exceed = max(zs_width * 0.2, 0.5)`

### v3.5.2：双重条件（最终版）
**驱动案例**：恒瑞医药中枢#7 区宽=1.36，笔#47超ZG仅 **1.6%**（0.91/57.44），v3.5.1 阈值 0.5 误判。

改为 AND 双条件：
```python
exceed_pct = exceed_zg / zs.zg          # 超ZG价的比例 > 3%
width_ratio = exceed_zg / zs_width      # 超区宽的比例 > 50%
if exceed_pct > 0.03 and width_ratio > 0.5:
    return True  # 结构破坏
```

效果对比：
| 股票 | 超ZG | v3.5 | v3.5.1 | v3.5.2 | 正确? |
|:----|:---:|:----:|:------:|:------:|:-----:|
| 沃森笔#27 | +2.28(18.4%) | 过滤 | 过滤 | 过滤 | ✅ |
| 恒瑞笔#47 | +0.91(1.6%) | 过滤 | 过滤 | 保留 | ✅保留 |
| 分众 | 无突破 | 保留 | 保留 | 保留 | ✅ |

### 最终验证（510只全量）
候选股 185→168(-9%)，一买 39→20 只，类一买 62→67 只补位。
