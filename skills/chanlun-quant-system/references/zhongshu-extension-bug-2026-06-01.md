# P0-4: 中枢扩展算法bug

## 发现时间
2026-06-01，分析513330（恒生互联网ETF）时由用户指出。

## 问题描述

`_find_zhongshus()` 方法在判断中枢扩展时条件过于宽松，导致离开笔被错误纳入原中枢，从而遗漏下方新形成的中枢。

### 问题代码位置

`generate_analysis.py:272-277`，`_find_zhongshus()` 方法

```python
# 当前错误逻辑（简化）
if next_high >= zd and next_low <= zg:
    # 价格区间与中枢区间有重叠 → 扩展中枢
```

### 具体案例：513330的笔25~27

| 笔 | 方向 | 最低价 | 最高价 | 说明 |
|---|:----:|:-----:|:-----:|------|
| 笔24 | ↑ | 0.510 | 0.570 | 中枢3[0.510,0.540]的向上段（形成ZG=0.540） |
| 笔25 | ↓ | 0.410 | 0.570 | **向下离开中枢3**，最低0.410远低于中枢ZD=0.510 |
| 笔26 | ↑ | 0.410 | 0.450 | 反弹，最高0.450 < 中枢3 ZD=0.510 |
| 笔27 | ↓ | 0.390 | 0.450 | 再探新低，最高0.450 < 中枢3 ZD=0.510 |

当前算法检查笔25区间[0.410, 0.570]与中枢3区间[0.510, 0.540]重叠 → `0.570≥0.510且0.410≤0.540`为True → 笔25被纳入中枢3扩展。后续笔26/27也因同样条件被纳入。

**问题**：笔25是中枢3的向下离开段，笔26/27的端点（最高0.450）**均未回到中枢3区间**内（ZD=0.510），根据缠论，离开中枢的笔不应参与该中枢的扩展判定。

### 正确的中枢划分

笔25、26、27三笔重叠区间构成一个新的**中枢4**：
- ZG = min(笔25高=0.570, 笔26高=0.450, 笔27高=0.450) = **0.450**
- ZD = max(笔25低=0.410, 笔26低=0.410, 笔27低=0.390) = **0.410**
- 中枢4区间 = **[0.410, 0.450]**

### 与已审计bug的关系

这个bug不在2026-05-31的审计范围内。审计查的是评分逻辑和信号质量，而这个是**中枢划分的底层算法错误**，发生在所有后续分析之前。一旦中枢划分错误，后续所有基于该中枢的买卖点判定、评分都会偏移。

## 修复方案

### 缠论理论依据

中枢扩展的规则（《教你炒股票》原文阐释）：

1. 一个中枢**一旦形成**（至少3笔重叠），其后的第一笔若离开中枢区间，称为**离开段**
2. 离开段之后，后续笔的**端点必须回到原中枢区间内**（回到ZG/ZD之间），才能判定为中枢扩展
3. 若离开段后的所有笔均未回到原中枢区间，则这些笔应构成**独立的新中枢**
4. 扩展后中枢的区间 = 扩展前的ZG/ZD与扩展笔构成的新笔集合的Z G/ZD的并集

### 实际应用的修复（2026-06-01）

在 `generate_analysis.py:_find_zhongshus()` 的扩展 while 循环中增加**穿透笔检查**：

```python
# === 修复前 ===
while end_idx < len(bis):
    next_bi = bis[end_idx]
    next_high, next_low = max(next_bi.start_price, next_bi.end_price), min(next_bi.start_price, next_bi.end_price)
    if next_high >= zd and next_low <= zg:
        end_idx += 1
    else: break

# === 修复后 ===
while end_idx < len(bis):
    next_bi = bis[end_idx]
    next_high, next_low = max(next_bi.start_price, next_bi.end_price), min(next_bi.start_price, next_bi.end_price)
    # 穿透笔检查：笔完全穿过中枢区间（高点≥ZG且低点≤ZD）
    # 这是中枢的离开段，不应扩展中枢
    if next_high >= zg and next_low <= zd:
        break
    if next_high >= zd and next_low <= zg:
        end_idx += 1
    else: break
```

### 修复原理

**穿透笔（piercing bi）**的定义：一笔的完整价格区间**包含**整个中枢区间，即 `next_high >= zg AND next_low <= zd`。

为什么这个条件能正确工作：

| 笔类型 | 与中枢关系 | 示例（中枢[0.510-0.540]） | 判定 |
|:------|:----------|:-------------------------|:----:|
| **穿透笔（离开段）** | 高点≥ZG **且** 低点≤ZD | 笔25[0.410-0.570]：0.570≥0.540 ✓, 0.410≤0.510 ✓ | **← break，终结中枢** |
| **普通重叠笔** | 高点≥ZD 且 低点≤ZG（但不满足穿透） | 典型：笔[0.520-0.560]：0.560≥0.510 ✓, 0.520≤0.540 ✓, 但0.520>0.510→不满足穿透 | 扩展中枢 |
| **区间内笔** | 完全在中枢内 | 笔[0.520-0.530]：0.530≥0.510 ✓, 0.520≤0.540 ✓ | 扩展中枢 |
| **偏出笔（单侧突破）** | 只有一端突破中枢 | 笔[0.530-0.560]：0.560≥0.510 ✓, 0.530≤0.540 ✓, 但0.530>0.510→不满足穿透 | 扩展中枢 |

关键洞察：一笔如果**从ZG上方出发，跌穿ZD下方**（或反之），说明这笔的力度足以完全离开当前中枢区间。此时它应被识别为离开段，而非中枢内部波动。

## 影响范围

- **P0级**：影响所有缠论分析中涉及多中枢趋势判断的场景
- **直接后果**：
  - 漏报新中枢 → 背驰对照对错误（用错参考中枢）
  - 一买判定可能使用错误的中枢作为下跌趋势的"最后一个中枢"
  - 三买判定时，突破中枢的参考基准出错
  - 中枢下移趋势被误判为中枢扩展（趋势强度被低估）

## 验证方法

以513330为例，修复后：
1. 应输出中枢3[0.510, 0.540]和中枢4[0.410, 0.450]两个独立中枢
2. 中枢3的下方应有向下离开笔25作为链接
3. 中枢4的笔25~27构成底背驰的最后一个中枢，笔27为背驰段
4. 底背驰判定结果应与当前一致（笔25 vs 笔27的DIF/MACD对比）

## 临时规避

在不修复核心算法的情况下，可以：
1. 在分析脚本中手动检查最新几笔是否构成新中枢
2. 若发现遗漏，在报告中手动标注"算法遗漏的中枢"作为补充
