# 部分股票索引越界故障记录

## 问题描述

`validate_tech_score.py` 对某些股票运行时，输出标记为 ❌，报错：
```
❌ single positional indexer is out-of-bounds
```

## 当前已知受影响标的

| 代码 | 名称 | 首次发现 | 是否反复出现 |
|------|------|----------|-------------|
| 600298 | 安琪酵母 | 2026-05-06 | 是 |
| 300772 | 运达股份 | 2026-05-06 | 是 |
| 300059 | 东方财富 | 2026-05-15 | 是 |

## 影响范围

- 失败股票不参与技术评分验证（不计入信号统计、评分均值、相关系数计算）
- `error_rate` 指标仍显示 0.0%，因为 `validate_tech_score.py` 的 error 检测仅检查 signal.error 字段，未捕获 `BacktestEngine.run_backtest()` 层面的异常
- 不影响其他 17 只股票的分析结果

## 根因推测

`backtest_engine.py` 中回测逻辑的 indice 计算在特定数据长度下越界。可能触发场景：
- 日线数据行数不足某个阈值时，回测窗口计算出现负索引
- 30分钟数据的时间切片超出范围

## 监控建议

- 每次运行报告输出时，肉眼检查 ❌ 标记数量
- 如果只有上述 3 只且不扩大 → 边界条件 bug，非系统性退化
- 如果名单扩大 → 需深入调试 backtest_engine
