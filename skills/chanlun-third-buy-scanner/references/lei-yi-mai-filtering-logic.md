# 类一买信号过滤 — 技术细节

## 问题背景

类一买（盘整底背驰）是缠论中最容易被误用的信号。缠论原文中，盘整背驰的可靠性低于趋势背驰，但在量化系统中如果不加区分，会导致：

1. **趋势下跌中反复触发**：每次下跌笔的MACD面积都可能比前一次小（空方逐步衰竭），但股价就是不反转
2. **越抄越亏**：投资者按信号买入，结果买在下跌中继

## 同仁堂案例（2025年9月后）

```
中枢ZD序列：47→41→35→38→36→33→31→28
MACD面积：每次下跌笔都比前一次小
结果：反复触发类一买，但股价从未反转
```

## 艾力斯案例（2026年5月）

```
中枢ZD序列：37→55→75→92→103→89
趋势：涨了3倍后回调14%
结果：类一买信号合理，是正常回调
```

## 判断逻辑

```python
# 两个条件同时满足才认定为趋势下跌
# 条件①：最近3个中枢ZD连续下移
consecutive_down = all(zd[i] > zd[i+1] for i in range(len(zd)-1))
# 条件②：整体趋势下降（最近5个中枢ZD下降超过5%）
overall_down = trend_zd[-1] < trend_zd[0] * 0.95
```

**为什么需要两个条件**：
- 只看条件①：会误伤"冲高回落"（如艾力斯103→89）
- 只看条件②：会漏掉"缓慢阴跌"（如同仁堂47→28）
- 两个同时满足：精准识别真正的趋势下跌

## 修复效果（2026-05-30验证）

| 指标 | 修复前 | 修复后 |
|------|--------|--------|
| 候选数（score≥3）| 76只 | 76只 |
| 类一买信号 | 33只 | 33只 |
| 其中中枢下移 | 0只（未识别）| 4只（精准识别）|
| 同仁堂score | 4 | 2（降级，不进候选）|
| 艾力斯score | 4 | 4（未降级，正常回调）|

## 演进过程

1. **第一版**：`zd_values[-1] < zd_values[0]` → 太简单，13只被误降级
2. **第二版**：加"连续下移"+"整体趋势下降" → 精准到4只
