# 缠论买点分类完整参考

## 标准缠论买点（3种）

### 一买（趋势背驰点）
- **定义**：下跌趋势末端，最后一段下跌与前一段下跌出现底背驰
- **前提**：必须有下跌趋势（至少2个中枢下移）
- **背驰标准**：离开段MACD面积 < 进入段面积
- **确认状态**：confirmed=True（有向上笔确认）
- **score**：5

### 二买（回调确认点）
- **定义**：一买之后的第一次回调，不破一买的低点
- **前提**：必须先有一买作为锚点
- **条件**：回调低点 > 一买低点
- **score**：5

### 三买（中枢突破回踩点）
- **定义**：价格向上突破中枢ZG后，回踩不破ZG
- **前提**：必须有中枢+突破
- **条件**：突破ZG + 回踩低点 > ZG
- **score**：5

## 扩展买点（系统定义）

### 潜一买（等待确认）
- **定义**：背驰条件满足，但还没有向上一笔确认
- **前提**：必须有下跌趋势+背驰
- **与一买区别**：一买有向上笔确认，潜一买没有
- **score**：近期(≤30天)时为4，超30天或价格已涨时降至1-3（实际范围 1-4）
- **代码位置**：generate_analysis.py:613-630

### 类一买（盘整底背驰）
- **定义**：盘整中连续两个下跌笔的MACD力度显著衰减
- **前提**：不要求下跌趋势，盘整即可
- **背驰标准**：MACD柱面积缩减到40%以下
- **过滤条件**：最近5个中枢ZD上涨超过10% → 上涨趋势 → 不触发
- **score**：极强背驰(area≤20%)=4 / 强背驰(area≤30%)=3 / 温和背驰(area≤40%)=2；中枢下移降级时为 0-2
- **代码位置**：pool_scanner.py:_detect_panbei_divergence()

### 反转后三买
- **定义**：趋势反转后新中枢的三买
- **前提**：下跌趋势被反向中枢确认反转
- **与二买区别**：二买必须先有一买确认，反转后三买只需趋势反转确认
- **score**：5
- **代码位置**：pool_scanner.py:_detect_post_reversal_buy()

### 三买形成中
- **定义**：突破ZG后回踩未成笔
- **状态**：
  - 深回踩(≥5%)：score=5
  - 浅回踩(3-5%)：score=4
  - 微回踩(2-3%)：score=3

### 中枢下沿机会（原名"潜在一买"）
- **定义**：价格在中枢下沿附近+MACD改善
- **性质**：结构位置评分，不是买点信号
- **score**：2（不进候选池）
- **注意**：已改名避免与缠论一买混淆

## 无效/过滤信号

### 潜一买(上涨趋势,无效)
- **定义**：上涨趋势回调中的一买信号
- **过滤条件**：最近5个中枢ZD上涨超过10%
- **score**：0

### 下跌趋势中
- **定义**：无任何买点信号
- **score**：0

## 理论可靠性排序

```
最可靠 ←─────────────────────────────────────────→ 最不可靠

标准一买(5) = 二买(5) = 三买(5)
    │
    ├── 潜一买(4)：理论可靠，缺确认
    │
    ├── 反转后三买(5)：趋势反转后的机会
    │
    ├── 类一买(3-4)：盘整背驰，可靠性中等
    │
    ├── 三买形成中(3-5)：观察中，未成笔
    │
    └── 中枢位置机会(2)：结构位置，非买点
```

## 关键区分

### 潜一买 vs 类一买
| 维度 | 潜一买 | 类一买 |
|------|--------|--------|
| 前提 | 必须有下跌趋势 | 盘整即可 |
| 背驰标准 | 趋势背驰 | MACD面积<40% |
| 理论基础 | 标准一买 | 盘整底背驰 |
| 确认状态 | confirmed=False | 无confirmed概念 |

### 反转后三买 vs 二买
| 维度 | 反转后三买 | 二买 |
|------|-----------|------|
| 前提 | 趋势反转确认 | 一买确认 |
| 锚点 | 新中枢的ZG | 一买的低点 |
| 可靠性 | 中（只有结构支撑） | 高（有背驰支撑） |
| 触发条件 | 宽松（只需趋势反转） | 严格（必须先有背驰） |
