# 类一买信号泛滥问题分析（2026-05-30）

## 问题描述

用户报告A500选股中大量出现类一买信号，担心类似同仁堂2025年9月后连续下跌反复触发买点。

## 根因分析

### 1. 类一买检测条件在箱体震荡/趋势下跌中过于宽松

`pool_scanner.py:223-320` 的 `_detect_panbei_divergence()` 四个条件：

| 条件 | 在箱体震荡中 | 在趋势下跌中 |
|------|------------|------------|
| ①价格不创新低(≤2%) | ✅ 满足（箱底支撑） | ❌ 通常不满足（持续新低） |
| ②MACD面积<40% | ✅ 满足（空方逐步衰竭） | ✅ 可能满足 |
| ③当前价>第二笔低点 | ✅ 满足（反弹1%即算） | ❌ 通常不满足 |
| ④MACD金叉/接近金叉 | ✅ 满足（震荡中频繁金叉） | ❌ 通常为死叉 |

**关键**：条件①②③④在"中枢下移的震荡下跌"中**全部可以满足**，但股价并不真正反转。

### 2. P0级进入段选取bug（已修复）

审计报告CRITICAL-2：代码取"最后一个中枢的进入段"vs"离开段"比较MACD面积，这实质上是**盘整背驰**的判断，而非**趋势背驰**。

缠论原文（第62课）要求：
- enter_bi = 趋势**第一个中枢**的进入段
- leave_bi = 趋势**最后一个中枢**的离开段

结果：大量盘整背驰被误判为趋势一买，加剧类一买信号泛滥。

### 3. 类一买代理confirmed判断bug（已修复）

审计报告P1-4：`pool_screener.py:698` 用 `!= '类一买'` 精确匹配，但pool_scanner输出的是 `"类一买(盘整底背驰)"`（含括号），导致类一买通过代理路径获得与标准一买相同的高评分。

## 区分真盘整 vs 假盘整

```python
# 检查最近3个中枢的ZD是否在下移
zs_list = analyzer.zhongshus[-3:]
zd_values = [float(z.zd) for z in zs_list]

if zd_values[-1] < zd_values[0] * 0.97:
    # 中枢下移>3% → 趋势下跌 → 类一买不可靠
    verdict = "假盘整（趋势下跌）"
else:
    # 中枢基本持平 → 真盘整 → 类一买可参考
    verdict = "真盘整"
```

## 建议修改

在 `pool_screener.py` 的后处理中，对类一买候选增加"中枢不下移"前置过滤，或至少在报告中打上"中枢下移"标记供人工判断。
