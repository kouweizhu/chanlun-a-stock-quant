# 缠论买点分类体系 — 理论与实践修正记录

## 日期：2026-05-30
## 修正背景

用户在A500选股中发现大量"类一买"信号，担心类似同仁堂（2025年9月后持续下跌）的走势。经审查发现三个问题：

1. **类一买在上涨趋势中误触发** — 上涨后的正常回调被识别为类一买
2. **"潜在一买"命名混淆** — 与缠论一买概念冲突
3. **进入段选取偏差**（已修复） — 盘整背驰被误判为趋势一买

## 修正内容

### 1. 类一买趋势过滤

**问题**：`_detect_panbei_divergence()` 只看"连续两个下跌笔的MACD力度衰减"，没有检查整体趋势方向。上涨趋势中的正常回调衰竭被误识别为类一买。

**修复**：增加条件⑤ — 趋势方向检查

```python
# 最近5个中枢ZD上涨超过10% → 上涨趋势 → 不触发类一买
zhongshus = analyzer.zhongshus
if len(zhongshus) >= 3:
    lookback = min(5, len(zhongshus))
    trend_zs = zhongshus[-lookback:]
    trend_zd = [float(z.zd) for z in trend_zs]
    if trend_zd[-1] > trend_zd[0] * 1.10:
        return 0, "", None  # 上涨趋势中的回调，不是类一买
```

**同步修改**：`scan_stock()` 中标准买卖点路径的类一买处理也增加了相同检查。

**效果**：
- 修复前：33只类一买（含13只上涨趋势误报）
- 修复后：17只类一买（上涨趋势全部过滤）

### 2. 买点命名规范化

**问题**：`pool_scanner.py` 中的"潜在一买(中枢下沿+MACD改善)"容易与缠论一买混淆。

**修复**：
- `潜在一买(中枢下沿+MACD改善)` → `中枢下沿机会(下沿+MACD改善)`，score 3→2
- `潜在二买(中枢下沿+向上笔)` → `中枢下沿机会(下沿+向上笔)`，score 3→2

**理由**：这不是缠论买点信号，只是结构位置评分。降为2分后不进候选池（score≥3）。

### 3. 两种"潜在买点"的区分

| 类型 | 来源 | 含义 | 评分 |
|------|------|------|------|
| 潜一买（confirmed=False） | generate_analysis.py | 背驰条件满足，等待向上一笔确认 | 4（类一买） |
| 中枢下沿机会 | pool_scanner.py | 价格在中枢下沿+MACD改善，结构位置 | 2（不进候选） |

## 缠论理论依据

- **一买**：下跌趋势末端的背驰 → 趋势反转信号
- **类一买（盘整底背驰）**：盘整区间内的底背驰 → 区间底部反弹
- **都不是**：上涨趋势中的回调 → 这是三买或二买的范畴
