# 类一买（盘整底背驰）信号质量修复

**日期**：2026-05-30
**版本**：v3.6
**问题来源**：用户跑A500选股时发现大量类一买信号，担心出现同仁堂式反复抄底被套

## 问题本质

盘整底背驰（类一买）在**趋势下跌**中会反复触发，但股价从未反转。

```
价格:  ╲    ╲    ╲    ╲    ╲
        ↑    ↑    ↑    ↑    ↑
       类一买 类一买 类一买 类一买 类一买
       (MACD面积逐次缩小，但中枢持续下移)
```

### 根因分析

1. **类一买检测逻辑缺陷**：`_detect_panbei_divergence()` 只看MACD面积衰竭，不区分"盘整"和"趋势下跌"
2. **标准一买路径同样有缺陷**：`confirmed=False` 的一买被标记为类一买，但未检查中枢趋势
3. **评分过高**：类一买评分 5/4/3，与标准一买等权，导致大量进入候选池

### 典型反例：同仁堂(600085)

```
中枢ZD序列: [47.0, 40.7, 35.3, 38.3, 36.2, 33.6, 31.4, 27.5]
最近3个ZD: [33.6, 31.4, 27.5] — 持续下移
```

修复前：score=4，进入候选池
修复后：score=2，不进入候选池

## 修复方案

### 修改1：`_detect_panbei_divergence()` — 新增条件⑤

在MACD金叉确认之后、评分之前，增加中枢趋势检查：

```python
# 条件⑤：中枢趋势检查
zhongshus = analyzer.zhongshus
zs_downgrade = False
if len(zhongshus) >= 3:
    recent_zs = zhongshus[-3:]
    zd_values = [float(z.zd) for z in recent_zs]
    if zd_values[-1] < zd_values[0]:  # 中枢下移 = 趋势下跌
        zs_downgrade = True
```

### 修改2：评分体系调整

| 场景 | 修复前 | 修复后 | 理由 |
|------|--------|--------|------|
| 盘整背驰（极强） | 5 | 4 | 可靠性低于趋势背驰 |
| 盘整背驰（强） | 4 | 3 | 同上 |
| 盘整背驰（温和） | 3 | 2 | 同上 |
| 中枢下移（极强） | 5 | 2 | 趋势延续，大幅降级 |
| 中枢下移（强） | 4 | 1 | 同上 |
| 中枢下移（温和） | 3 | 0 | 不推荐 |

### 修改3：标准买卖点路径的类一买

`scan_stock()` 中 `best_buy.level == 1 and not confirmed` 的路径，增加中枢下移检查：

```python
if best_buy.level == 1 and not getattr(best_buy, 'confirmed', True):
    buy_type_str = "类一买"
    best_score = max(1, best_score - 1)
    # 中枢下移检查
    if len(analyzer.zhongshus) >= 3:
        recent_zs = analyzer.zhongshus[-3:]
        zd_values = [float(z.zd) for z in recent_zs]
        if zd_values[-1] < zd_values[0]:
            best_score = max(1, best_score - 2)
            buy_type_str = "类一买(中枢下移)"
```

## 修复效果

| 指标 | 修复前 | 修复后 |
|------|--------|--------|
| 候选数（score≥3） | 76只 | 66只 |
| 类一买信号 | 33只 | 33只 |
| 其中中枢下移 | 0只（未识别） | 13只（被降级） |
| 同仁堂score | 4 | 2 |

## 关键设计原则

1. **盘整背驰 ≠ 趋势背驰**：盘整背驰的可靠性本就低于趋势背驰，评分应有差异
2. **中枢下移是趋势延续的信号**：即使MACD面积衰竭，如果中枢在下移，说明空方仍占主导
3. **宁可漏掉不可错入**：类一买信号宁可少报，不可反复触发导致越抄越亏

## 已知局限

- 中枢下移判断用的是"最近3个中枢的ZD"，如果中枢数量<3则不触发
- 未来可考虑：用更长窗口（5个中枢）或加权移动平均来判断趋势
- 可增加"价格在中枢下方"作为额外过滤条件
