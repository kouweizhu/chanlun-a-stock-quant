## 核心结论

日线表和30分钟表的覆盖范围、最新日期差异决定了多条件筛选的可行策略。以下实证数据来自 2026-05-20 全量验证。

## 最新日期漂移

### 全市场（515只）最新日期分布

- **2026-05-13**：大部分股票最新日线到此为止
- **2026-05-18**：仅 6 只（002415, 600298, 600872, 600887, 601155, 688036）
- **其他少数**：5/12, 5/15 等零星日期

### 30分钟表最新日期

- 大部分股票截止于 2026-05-15
- 30分钟数据比日线 **晚结束 2-3 天是常态**

### 影响

最新的日线底分型（5/13-5/18形成）对应的30分钟数据还没更新到那几天。所以即使日线筛选出底分型候选，**最近几天的30分钟结构验证必然不可行**。

实用对策：优先关注有最新日线+30分钟重叠区间的股票（即日线底分型在 5/15 之前形成的）。

## "严格30分钟三买"实证

在48只股票的30分钟数据中，用滑动窗口中枢近似法检测：

- **严格三买**（突破中枢→回踩不碰ZG→反弹确认）：**0 只**
- **类三买**（突破→回踩略进中枢→反弹确认）：5 只（688036 传音控股、600150 中国船舶、000938 紫光股份、600089 特变电工、688169 石头科技）
- 另有一部分是"偏二买"结构：回踩深度已接近中枢ZD

### 原因

1. 大盘蓝筹股30分钟走势以震荡为主，突破后回踩几乎必然碰ZG
2. 48只样本太小，严格三买在30分钟级别天然稀缺
3. 当前不是强趋势行情，突破后回踩幅度普遍较深

### 实用策略

接受"类三买"作为可选信号，判定条件：

```python
# 类三买判定条件
classification = "类三买" if (
    breakout                  # 突破中枢上沿
    and pullback_low > zs.zd  # 回踩至少不跌破中枢下沿
    and bounce                # 最新3根有反弹迹象
) else "无法确认"
```

严格三买 `pullback_low > zs.zg` 在实际样本中几乎找不到，不建议作为筛选条件使用。

## 推荐筛选策略

当目标为"日线底分型 + 30分钟三买 + 放量"时：

1. **先用日线 SQL 筛底分型+放量**（515只全做）
2. **交叉检查候选是否在48只中**
   - 是 → 尝试30分钟类三买验证
   - 否 → 标注"仅日线信号可用"
3. **30分钟验证接受类三买**，不要苛求严格三买
4. **优先处理有最新日线数据的6只**（002415/600298/600872/600887/601155/688036），它们的日线信号最新

## 实操速查

### 查某只股票是否在30分钟表中

```sql
SELECT COUNT(*) FROM kline_30min WHERE stock_code = '688036';
-- >0 即有30分钟数据
```

### 查30分钟最新日期

```sql
SELECT stock_code, MAX(date) as last_date
FROM kline_30min GROUP BY stock_code
ORDER BY last_date DESC;
```

### 查日线最新日期

```sql
SELECT stock_code, MAX(date) as last_date
FROM kline_daily GROUP BY stock_code
ORDER BY last_date DESC;
```
