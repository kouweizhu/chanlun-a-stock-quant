# 最新季报点评模板（v4.2.3）

> 用于 Step 7.2 报告输出中的"最新季报点评"章节。每份个股分析报告**必须**包含此章节。

## 数据来源

| 字段 | 位置 | 说明 |
|:-----|:-----|:------|
| 报告期 | `data_date` | 如 20260331=Q1 2026 |
| 营收 | `profitability.totalRevenue` | 当季营收绝对值（元），除以1e8转亿 |
| 归母净利 | `profitability.netProfit` | 当季归母净利（元） |
| 扣非净利 | `profitability.deductedProfit` | 当季扣非净利（元） |
| 营收同比 | `growth.YOYRevenue` | 小数转百分比（0.6639→+66.4%） |
| 净利同比 | `growth.YOYNI` | 小数转百分比 |
| 毛利率 | `profitability.gpMargin` | 小数转百分比 |
| 净利率 | `profitability.npMargin` | 小数转百分比 |
| ROE | `profitability.roeAvg` | 单季ROE，年化需×4 |
| 负债率 | `health.liabilityToAsset` | 小数转百分比 |
| 经营现金流/营收 | `health.CFOToOR` | 小数转百分比，负值表示回款差 |
| 利润质量 | `profitability.profitQuality` | 扣非/归母，>0.9优质 |

> ⚠️ **注意**：`multi_year_data` 只有年度数据。最新季度数据在顶层 `profitability/growth/health` 字段中，不要从 multi_year_data 中找。

## 标准格式

```markdown
### Q1 2026 季报点评

**核心判断：** [一句话总结——营收加速/放缓？利润改善/恶化？核心矛盾是否改变？]

| 指标 | Q1 2026 | 同比/环比变化 | 评价 |
|:----|:--------:|:------------:|:-----|
| 营收 | XX亿 | **+XX%** | 🟢/🟡/🔴 说明 |
| 归母净利 | XX亿 | **+XX%** | 🟢/🟡/🔴 说明 |
| 扣非净利 | XX亿 | — | 🟢/🟡/🔴 说明 |
| 毛利率 | XX% | 较上年±Xpct | 🟢/🟡/🔴 说明 |
| 净利率 | XX% | 较上年±Xpct | 🟢/🟡/🔴 说明 |
| 经营现金流/营收 | XX% | 正/负 | 🟢/🟡/🔴 说明 |
| ROE(年化) | ≈X% | 较上年±Xpct | 🟢/🟡/🔴 说明 |
```

**🟢/🟡/🔴 判定规则：**

| 指标 | 🟢 利好 | 🟡 中性 | 🔴 利空 |
|:-----|:--------|:--------|:--------|
| 营收同比 | >+20% | +5%~+20% | <+5%或负增长 |
| 净利同比 | >+15% | 0%~+15% | 负增长 |
| 毛利率变化 | +>2pct | ±2pct以内 | -<2pct |
| 净利率变化 | +>1pct | ±1pct以内 | -<1pct |
| 经营现金流/营收 | >0% | — | <0%（负值） |
| ROE年化 | >10% | 5%~10% | <5% |

## 点评要点（必写）

1. **营收增速判断**：加速还是放缓？是否反映行业景气度？
2. **利润质量**：利润增速是否匹配营收增速？增收不增利是否加剧？
3. **毛利率趋势**：企稳、改善还是继续恶化？原因是什么（价格战/成本下降/产品结构）？
4. **现金流状况**：经营现金流为正还是负？回款周期是否拉长？
5. **综合判断**：最新季报是否改变了之前的核心结论？拐点信号出现还是恶化确认？

## 实战案例：运达股份（300772）Q1 2026

```markdown
### Q1 2026 季报点评

**营收加速但利润恶化，增收不增利格局加剧：**

| 指标 | Q1 2026 | 同比变化 | 评价 |
|:----|:--------:|:--------:|:-----|
| 营收 | 66.73亿 | **+66.4%** | 🟢 大幅增长，订单交付加速 |
| 归母净利 | 0.48亿 | **-18.7%** | 🔴 营收增66%利润反降，价格战侵蚀 |
| 扣非净利 | 0.38亿 | — | 🔴 利润质量80%，依赖非经常性损益 |
| 毛利率 | 8.03% | 较2025全年+0.4pct | 🟡 略有企稳但仍在低位 |
| 净利率 | 0.65% | 较2025全年-0.5pct | 🔴 利润率进一步压缩 |
| 经营现金流/营收 | **-18.6%** | 负值 | 🔴 现金流恶化，回款压力大 |
| ROE(年化) | ≈2.2% | 较2025全年-2.7pct | 🔴 资本回报率极低 |

**核心判断：** Q1营收+66.4%说明在手订单确实在加速交付，但净利-18.7%说明风电价格战仍在持续，毛利率8.03%仅比2025全年微升0.4pct，远不足以覆盖运营成本。净利率0.65%意味着每卖100元产品只赚0.65元，经营现金流/营收为-18.6%说明回款质量差。**增收不增利格局在Q1进一步加剧，未见拐点。**
```
