# 基本面趋势分析 — 方法论（v2.0）

## 概述

`hithink_fundamental.py` v2.0 新增 4 年财务趋势分析，基于连续 4 年年报数据（2022→2025）判定各维度变化方向，生成趋势修正评分。

**核心逻辑**：财务趋势比绝对值更能反映公司的真实经营方向。一家 ROE 从 20% 持续下降至 12% 的公司，即使当前 12% 仍不错，趋势走弱也值得警惕。

## 分析维度

| 维度 | 数据来源 | 趋势类型 | 评分范围 |
|:----|:---------|:---------|:--------:|
| ROE趋势 | 4年ROE | 盈利能力变化方向 | -5 ~ +5 |
| 营收趋势 | 4年营收 | 规模扩张方向 | -5 ~ +5 |
| 毛利率趋势 | 4年销售毛利率 | 盈利质量变化 | -5 ~ +5 |
| 负债率趋势 | 4年资产负债率 | 财务风险变化 | -5 ~ +5 |
| 利润质量趋势 | 4年扣非/归母比率 | 利润含金量变化 | -5 ~ +5 |

## 趋势判定规则

对于每个维度，比较最近 4 个连续年报值（v1, v2, v3, v4）：

### 连续变化类

| 模式 | 判定 | 示例（ROE） |
|:----|:-----|:------------|
| v1>v2>v3>v4 或 v1≥v2≥v3≥v4 | **持续下降** | 18.9→18.0→16.1→15.2 → 下降(-5) |
| v1<v2<v3<v4 或 v1≤v2≤v3≤v4 | **持续上升** | 15→16→17→19 → 上升(+5) |
| 无单调趋势 | 见波动/震荡判定 | — |

### 波动/震荡类

当数据不满足单调递增/递减时，检查中间年份的波动：

| 模式 | 判定 | 评分 |
|:----|:-----|:----:|
| 先升后降（v1↑v2↑v3↓v4↓） | **先升后降** | -2 |
| 先降后升（v1↓v2↓v3↑v4↑） | **先降后升** | +2 |
| 中间小幅波动（幅度<1%） | **稳定** | 0 |
| 大幅震荡（幅度>5%） | **大幅波动** | -1 |

### 利润质量特殊判定

利润质量 = 扣非归母净利润 / 归母净利润。>0.9 为优质，<0.7 为差。

| 4年比率趋势 | 判定 | 评分 |
|:-----------|:-----|:----:|
| 连续4年 > 0.9 | **持续高质** | +3 |
| 连续4年 < 0.7 | **持续低质** | -5 |
| 逐年改善（0.7→0.8→0.9→0.95） | **改善趋势** | +5 |
| 逐年恶化（0.95→0.9→0.8→0.7） | **恶化趋势** | -5 |
| 中间波动 | **稳定** | 0 |

## 综合修正计算

```python
total_correction = roe_score + revenue_score + margin_score + liability_score + profitQuality_score
# 范围：-17 ~ +14
# 负值：基本面趋势走弱，需要调低snapshot评分
# 正值：基本面趋势走强，可以调高snapshot评分

adjusted_total = total_score + total_correction
# 范围：0~100，被截断到有效范围
```

## 实战案例

### 案例1：爱尔眼科(300015) 2026-05-14

| 维度 | 4年数据 | 趋势 | 评分 |
|:----|:--------|:-----|:----:|
| ROE | 18.0→18.9→18.0→15.2 | 持续下降 | -5 |
| 营收(亿) | 161→204→210→224 | 持续上升 | +3 |
| 毛利率 | 52.8→50.8→49.7→48.6 | 持续下降 | -4 |
| 负债率 | 30.1→30.5→30.8→31.2 | 微幅上升 | -1 |
| 利润质量 | 0.96→0.97→0.97→0.97 | 持续高质 | +3 |

**综合修正 = -5+3-4-1+3 = -4**
**snapshot评分 = 77, 修正后 = 73**

解读：营收仍在扩张但盈利能力（ROE+毛利率）持续走弱，利润质量虽高但不足以抵消。趋势走弱是扣分项，但非致命。

### 案例2：万科A(000002) 2026-05-14

| 维度 | 4年数据 | 趋势 | 评分 |
|:----|:--------|:-----|:----:|
| ROE | 9.6→4.9→1.4→0.5 | 持续下降 | -5 |
| 营收(亿) | 5038→4657→3432→2850 | 持续下降 | -5 |
| 毛利率 | 19.2→15.2→12.5→10.1 | 持续下降 | -5 |
| 负债率 | 75.3→73.2→74.8→77.1 | 高位震荡 | -1 |
| 利润质量 | 0.85→0.82→0.79→0.75 | 恶化趋势 | -1 |

**综合修正 = -5-5-5-1-1 = -17**
**snapshot评分 = 32, 修正后 = 15**

解读：所有维度同步恶化，典型的地产周期下行特征。

### 案例3：立讯精密(002475) 2026-05-14

| 维度 | 4年数据 | 趋势 | 评分 |
|:----|:--------|:-----|:----:|
| ROE | 23.1→22.5→21.8→22.1 | 先降后升 | +2 |
| 营收(亿) | 2140→2319→2456→2780 | 持续上升 | +3 |
| 毛利率 | 12.0→11.5→11.2→11.5 | 先降后稳 | 0 |
| 负债率 | 63→64→65→66 | 微幅上升 | -1 |
| 利润质量 | 0.95→0.94→0.93→0.93 | 稳定 | +1 |

**综合修正 = 2+3+0-1+1 = +5**
**snapshot评分 = 47, 修正后 = 52**

解读：营收扩张强劲，ROE在下降后企稳回升，趋势改善。

## 在报告中的应用

趋势修正后的 `adjusted_total` 替代原始 `total_score` 用于综合加权计算。报告中应同时输出原始评分和修正后评分，并在推理链中说明修正原因。

**报告格式示例**：
```
基本面评分：77（snapshot）→ 73（趋势修正 -4）
趋势分析：ROE持续下降(-5) + 营收持续上升(+3) + 毛利率持续下降(-4) + 负债率微升(-1) + 利润质量高(+3) = -4
```
