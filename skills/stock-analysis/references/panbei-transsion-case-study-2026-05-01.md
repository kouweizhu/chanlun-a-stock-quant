# 盘整背驰实战案例：传音控股(688036) 2026-05-01

## 背景

2026-05-01 对传音控股(688036)进行三维分析时，`quick_chanlun.py` 输出显示最近信号为三卖(2026-02-11 @61.68, 置信度2)，且没有后续一买信号。技术面评分按照标准规则计算：

```
+15(最新笔向上) + 20(突破中枢上沿) + 10(MACD金叉) - 8(三卖未消耗) = 37分
```

但用户反馈：「股价在3月底到4月初没有形成买一吗？我看着有点像底背离啊」。这提示了 **盘整背驰（盘背）** 信号未被算法识别。

## 结构分析

### 最近5笔

```
笔① ↑ 02-04(57.07)→02-11(61.68)
笔② ↓ 02-11(61.68)→03-23(50.80)  ← 离开中枢6的向下笔
笔③ ↑ 03-23(50.80)→03-31(57.42)
笔④ ↓ 03-31(57.42)→04-13(51.04)  ← 离开中枢7的向下笔
笔⑤ ↑ 04-13(51.04)→04-28(62.46)  ← 最新笔向上 ✅
```

### MACD面积对比

| 指标 | 笔②(02-11~03-23) | 笔④(03-31~04-13) | 缩减比例 |
|:---|:--------------:|:--------------:|:--------:|
| 价格低点 | 50.99 | 51.50 | +1%（更高） |
| DIF累计面积 | 39.00 | 11.76 | **30.2%** |
| MACD柱面积 | 9.38 | 1.62 | **17.3%** ✅ |

**关键发现：**
- 价格：笔④低点(51.50) > 笔②低点(50.99) — 未创新低
- 力度：MACD柱面积只剩17.3% — **极度显著背驰**
- 这就是典型的**盘整背驰：价格未新低 + 力度极度萎缩**

### 为什么算法没识别

`quick_chanlun.py` 的BuySellPoint检测逻辑要求：
1. 标准一买：离开段价格新低 + MACD底背驰
2. 这里笔④低点(51.50) > 笔②低点(50.99)，价格未新低 → 不触发一买条件

实际上形成的是**盘整背驰（盘背）/类一买**，标准缠论分类中属于盘整走势的背驰，不是趋势背驰。

## 评分修正

应用盘背修正规则后：

```
原评分:   +15(笔向上) + 20(突破中枢) + 10(金叉) - 8(三卖) = 37分
修正:     +15(笔向上) + 20(突破中枢) + 10(金叉) - 4(三卖减半) + 10(盘背) = 51分
```

技术面从37分提升至51分，提升14分。

## 对最终决策的影响

| 项目 | 原评分(37) | 修正后(51) |
|:----|:----------:|:----------:|
| 综合评分(40%权重) | 14.8 | 20.4 |
| 综合评分(加权) | 59.8→60 | 65.4→65 |
| 决策 | 关注(60-70边界) | 关注(65分, 成长性≥15可上调至推荐) |
| 仓位 | 10%-20% | 15%-25%（可适度上调） |

## 教训与流程改进

1. **盘整背驰是高频实战信号** — 笔④相比笔②MACD面积只剩17%，这种极端的力度萎缩在实战中是非常可靠的底部信号，不应因算法没标记就忽略
2. **用户提问是信号** — 用户是缠论实战者，他注意到K线形态并质疑时，大概率是对的。应快速验证而非辩解
3. **修复动作** — 在SKILL.md的Step 2.4中新增「盘整背驰检测」子步骤，确保每次分析都主动检查盘背

from data_manager import DataManager
dm = DataManager()
bars = dm.get_klines('688036', level='daily')  # 返回 pandas.DataFrame

# MACD计算（12/26/9）

ema26 = closes.ewm(span=26).mean()

# 区间面积计算
import pandas as pd
df['macd_bar'] = macd_bar
area_bi2 = df[(df['date'] >= '2026-02-11') & (df['date'] <= '2026-03-23')]['macd_bar'].abs().sum()
area_bi4 = df[(df['date'] >= '2026-03-31') & (df['date'] <= '2026-04-13')]['macd_bar'].abs().sum()
ratio = area_bi4 / area_bi2
print(f'盘整背驰比率: {ratio:.1%}')
