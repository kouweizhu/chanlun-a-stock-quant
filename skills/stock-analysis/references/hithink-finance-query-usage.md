# hithink-finance-query 使用指南

## 概述

同花顺 `hithink-finance-query` 是 `query2data` 接口的财务数据版，返回结构化财务指标（营收、净利、ROE、毛利率、负债率等）。

**优势**：自带最新报告期数据（Q1/半年报/三季报/年报），无需手动 EastMoney 修正。

## API 调用

```bash
curl -s -X POST "https://openapi.iwencai.com/v1/query2data" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $IWENCAI_API_KEY" \
  -H "X-Claw-Skill-Id: hithink-finance-query" \
  -H "X-Claw-Skill-Version: 1.0.0" \
  -d '{"query":"300015 营业收入 归母净利润 ROE 销售毛利率 销售净利率 资产负债率","page":"1","limit":"5","is_cache":"0","expand_index":"true"}'
```

## 已知陷阱

### 1. 查询长度限制

**症状**：返回 `status_code: -3001`，`datas` 为空数组。

**原因**：query 字符串过长时 API 拒绝处理。实测约 200+ 字符的 query 会触发此限制。

**解决**：将长查询拆分为多次短调用：
- 第1次：最新财务数据（~15个指标）
- 第2次：多年度趋势数据（~20个指标）
- 第3次：估值数据（通过 `hithink-market-query`）

### 2. 字段名敏感

**症状**：某些字段名在长查询中不返回，但在短查询中正常返回。

**示例**：
- `毛利率` 在含 `净利率` 的长查询中可能不返回
- 改用 `销售毛利率` 可解决

**规则**：使用完整字段名（`销售毛利率` 而非 `毛利率`，`销售净利率` 而非 `净利率`，`资产负债率` 而非 `负债率`）。

### 4. 多年度查询

在字段名前加年份即可查询历史数据：

```
300015 2022营收 2023营收 2024营收 2025营收
300015 2022ROE 2023ROE 2024ROE 2025ROE
300015 2022销售毛利率 2023销售毛利率 2024销售毛利率 2025销售毛利率
```

返回键名格式：`营业收入[20221231]`、`净资产收益率[20231231]` 等。

### 5. 扣非净利润查询

扣非净利润字段名为 `扣非归母净利润`，支持多年度查询：

```
300015 扣非归母净利润
300015 2022扣非归母净利润 2023扣非归母净利润 2024扣非归母净利润 2025扣非归母净利润
```

返回键名格式：`扣非归母净利润[20251231]`。

**利润质量计算**：`利润质量 = 扣非归母净利润 / 归母净利润`。比率 > 0.9 为利润质量优质（利润主要来自主营业务），< 0.7 为利润质量差（依赖非经常性损益）。

### 6. 完整查询示例（hithink_fundamental.py v2.0 使用）

脚本 `hithink_fundamental.py` 将以下查询拆分为多次短调用：

**查询1 — 最新财务数据**：
```
300015 营业收入 归母净利润 扣非归母净利润 ROE 销售毛利率 销售净利率 资产负债率 基本每股收益 每股净资产 每股经营活动产生的现金流量净额 流动比率 速动比率 经营活动产生的现金流量净额 总资产
```

**查询2 — 多年度趋势数据**：
```
300015 2022营业收入 2023营业收入 2024营业收入 2025营业收入 2022归母净利润 2023归母净利润 2024归母净利润 2025归母净利润 2022扣非归母净利润 2023扣非归母净利润 2024扣非归母净利润 2025扣非归母净利润 2022ROE 2023ROE 2024ROE 2025ROE 2022销售毛利率 2023销售毛利率 2024销售毛利率 2025销售毛利率 2022资产负债率 2023资产负债率 2024资产负债率 2025资产负债率
```

**查询3 — 估值数据**（通过 `hithink-market-query`）：
```
300015 市盈率PE 市净率PB 股息率 总市值
```

### 5. 报告期判断

返回键名的 `[YYYYMMDD]` 后缀即为报告期：
- `[20260331]` = Q1 2026
- `[20250630]` = 半年报 2025
- `[20250930]` = 三季报 2025
- `[20251231]` = 年报 2025

扣非字段同样遵循此规则：`扣非归母净利润[20251231]`。

### 6. 数据可用性检查

如果某个年份的数据在返回中缺失（如 `营业收入[20221231]` 为空），原因可能是：
- 该股票当年尚未上市
- 同花顺API未收录该年度数据
- 查询字符串过长导致API截断

**应对**：优先使用 `multi_year_data` 中实际返回的年份数。如果仅返回2-3年而非4年，趋势分析仍可执行但置信度降低，应在报告中标注"仅X年数据可用"。

## 估值数据（hithink-market-query）

PE/PB/股息率/市值 通过 `hithink-market-query` 获取：

```bash
curl -s -X POST "https://openapi.iwencai.com/v1/query2data" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $IWENCAI_API_KEY" \
  -H "X-Claw-Skill-Id: hithink-market-query" \
  -H "X-Claw-Skill-Version: 1.0.0" \
  -d '{"query":"300015 市盈率PE 市净率PB 股息率 总市值","page":"1","limit":"5","is_cache":"0","expand_index":"true"}'
```

返回字段：
- `市盈率(pe,ttm)[YYYYMMDD]` — PE(TTM)
- `市净率[YYYYMMDD]` — PB
- `股息率[YYYYMMDD]` — 股息率(%)
- `总市值[YYYYMMDD]` — 总市值(元)
- `动态市盈率[YYYYMMDD]` — 动态PE

### 7. 趋势分析（v2.0 新增）

`hithink_fundamental.py` v2.0 输出 `trend_analysis` 段，包含各维度的4年趋势判定：

**判定规则：**
| 维度 | 趋势判定方法 | 评分修正 |
|:-----|:------------|:--------:|
| ROE趋势 | 比较2022→2025连续变化：持续上升→+3, 持续下降→-5, 高位震荡→0 | ±5 |
| 毛利率趋势 | 比较2022→2025连续变化：持续上升→+2, 持续下降→-4, 震荡→0 | ±4 |
| 营收趋势 | 比较2022→2025营收增速：持续加速→+3, 持续减速→-2, 稳定→0 | ±3 |
| 负债率趋势 | 比较2022→2025：持续降低→+2, 持续升高→-3, 稳定→0 | ±3 |
| 利润质量 | 扣非/归母比率：>90%→+3, >80%→+2, >70%→+1, <70%→-2 | +3~-2 |
| 综合修正 | 以上累加，范围-17~+14 | -17~+14 |

**输出示例：**
```json
"trend_analysis": {
    "roe_trend": "持续下降", "roe_correction": -5,
    "gross_margin_trend": "略降", "margin_correction": -2,
    "revenue_trend": "持续加速", "revenue_correction": +3,
    "debt_trend": "持续改善", "debt_correction": +2,
    "profit_quality": 0.95, "quality_correction": +2,
    "total_correction": -0
}
```

> ⚠️ 如果某年数据缺失（如股票2019年后才上市，仅有3年数据），趋势分析仍可执行但置信度降低，报告中标注"仅X年数据可用"。
