# 深套持仓决策框架 — 实操参考

> 本文件记录了三叉戟决策框架的实操案例和具体命令模板。
> 适用场景：用户已持有某只/多只股票深套中，询问持有/加仓/割肉。
> 与本技能 SKILL.md 的「深套持仓分析」节配合使用。

## 快速检查清单（回答前逐条过）

```
□ 查 policy: 行业是否有重大政策拐点？
□ 查 veto: 否决机制是否触发？
□ 查 tech: 是否有买入信号（底分型/金叉/一买）？
□ 查 compare: 如果多只持仓，哪只更强？
□ 查 macro: 行业是否处于底部区域（跌幅/估值/政策力度）？
```

## 行业政策拐点判断模板

当用户问地产股深套时，以下政策信息是核心：

```
1. 中央定调用语变化：止跌回稳→着力稳定
2. 资金工具：央行再贷款规模/利率/期限
3. 落地城市数：多少城已实施
4. 基本面数据：销售/房价/投资降速是否放缓
```

## 实操案例：金地+万科深套（2026-06-29）

**背景**：用户同时深套持有金地集团(600383)和万科A(000002)，两股跌幅均超85%。

**三叉戟判断结果**：

| 决策 | 金地集团 | 万科A | 理由 |
|:----|:--------:|:-----:|:-----|
| 加仓 | ❌ | ❌ | 综合评分<60，无买点信号，基本面亏损中 |
| 持有观望 | ✅ | ✅ | 政策底已现(6月国资收房)，跌幅85%+，无L3否决 |
| 割肉 | ⚪ 不建议 | ⚪ 不建议 | 政策面拐点/继续大幅下行空间有限 |

**关键政策信息**（该次分析的核心发现）：
- 2026年6月：中央定调从「止跌回稳」升级为「着力稳定房地产市场」
- 央行3000亿保障房再贷款(利率1.75%，最长5年)
- 全国超80城国资收房，6月上旬已完成1.8万套过户
- 《求是》杂志6月文章：政策力度要匹配市场预期，一次性给足
- 全国二手房实际成交价整体跌幅超四成（首次官方承认跌幅）

**关键推理链**：
1. 否决检查：万科触发"ROE连降5年+负债率76.9%>70%"→降级2档；金地不触发(负债率64.3%<70%)
2. 技术面：万科MACD已金叉（积极信号），金地仍死叉 → 万科相对更强
3. 基本面：金地亏损幅度小于万科（金地-25%ROE vs 万科-55%ROE），且负债率更低 → 金地基本面相对更强
4. 消息面：两者均为中性，万科略高(51.4vs47.4)
5. 综合评分：金地14.3分，万科21.8分（触发否决后仍为回避）
6. 政策面修正：两股均从"回避"上调至"观望"（政策底已现，但市场底尚未确认）

**输出触发条件清单**：
- 万科：等待日线底分型确认（MACD已金叉，只需价格结构配合），若回踩中枢下沿(3.76)放量突破可考虑减仓
- 金地：等待MACD金叉+底分型双重信号，当前仍处于死叉下跌通道，信号需更明确
