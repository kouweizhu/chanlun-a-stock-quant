# 财报披露日前后数据可靠性说明

## 问题

`quick_fundamental.py` 返回的 Baostock 财务数据在**年报/季报正式披露前后**的可靠性差异显著：

| 时间窗口 | 数据状态 | 风险 |
|:---------|:---------|:-----|
| 披露前 2~4 周 | Baostock 可能仍使用上期数据或预估数据 | 净利润/营收等指标可能严重偏离实际 |
| 披露日 ±1天 | Baostock 刷新数据（拉取交易所正式公告） | 数据转为实际值，可能与之前差异巨大 |
| 披露后 | 数据为实际公告值，可靠 | — |

## 实战案例：鲁西化工 000830 (2026-04)

| 分析日期 | 数据状态 | ROE | 净利YOY | 基本面分 | 备注 |
|:---------|:---------|:--:|:-------:|:--------:|:-----|
| 04-28 | 年报未出，数据存疑 | — | — | 60.5 | 4月28日分析 |
| 04-29 | **2025年报正式披露** | 4.82% | -55.28% | — | 年报数据为实际值 |
| 04-30 | 年报已出，数据可靠 | 4.82% | -55.28% | **40** | 降20.5分 |

#### 再次印证：同一模式在04-30 第二次分析时重现

2026-04-30 对鲁西化工的第二次分析时, 年报已于04-29正式披露, Baostock 数据已更新为实际值。基本面分从首次分析的60.5大幅降至40, 决策从"关注"降为"观望"。

**关键教训：** 这不是基本面恶化, 而是首次分析的输入数据是过期/预估值。两次分析的技术面和消息面基本稳定(技术52→60, 消息70→65), 唯有基本面跳跃, 佐证了变化根源是数据源切换。

### 分众传媒 002027 (2026-04-30) — 第一次分析

分众传媒是**首次分析**, 无历史对比, 但指出了潜在的数据时效性风险：

| 分析日期 | 数据状态 | 数据日期 | 下一份财报 |
|:---------|:---------|:---------|:-----------|
| 04-30 | 2025年报已出 | 2025-12-31 | 2026Q1季报(期限内) |

由于2025年报在分析时已出, Baostock 数据为实际值, 无跳跃风险。但在 Q1季报窗口期内, Q1数据可能尚未更新。

## 对分析流程的影响

### 1. 历史对比时的"虚假变化"

两次分析间基本面分的大幅波动可能并非公司基本面的真实变化，而是**数据源从预估切换到实际**的结果。在推理链中应明确区分：

```
评分变化说明：
→ 基本面从60.5降至40: 原因为年报(04/29)披露后数据更新
→ 实际净利-55.28% vs 此前Baostock预估值
→ 非基本面'恶化'，而是数据精确度提升
```

### 2. 数据置信度标注

在 JSON 输出的 `fund_weight_adjustments` 中标注 `data_recency`：

```json
{
  "data_recency": {
    "data_date": "2025-12-31",
    "next_report_date": "2026-04-29 (年报)",
    "data_status": "pre_report_estimate / post_report_actual",
    "notes": "年报披露前数据可能为预估，评分使用按此折价解读"
  }
}
```

### 3. 预防措施

- 如果 memory 显示**近期有年报/季报预约披露**，在 Step 1 中标注 `⚠️ 财报披露前后，基本面评分可能因数据更新发生跳跃`
- 对比两次分析的基本面分变化时，首先排除"数据从预估变为实际"这个原因
- 对 pre-report 分析的基本面分加 **± 10分 置信区间** 标注
- 如果 pre-report 和 post-report 的两份分析在短时间内连续（如本次间隔2天），在报告中明确解释评分差异的原因

## 数据来源字段检查

`quick_fundamental.py` 输出的 JSON 中有 `data_source` 和 `data_date` 字段：

```json
{
  "data_source": "baostock",
  "data_date": "2025-12-31",
  "fundamental_score": { ... }
}
```

- `data_date` 显示的是财报覆盖的截止日期（如 2025-12-31）
- 如果当前日期（如 2026-04-28）远晚于 data_date，且年报预约日已过但仍未更新 → 数据为陈旧值
- 如果 data_date 与最新财报季匹配 → 数据已更新
