## 关键洞察

### 1. 扣非净利润揭示真相
归母净利润波动巨大（-16.9亿→17.0亿→8.93亿→5.37亿），但扣非净利润稳定在5.2-6.7亿区间。说明：
- 2022年亏损 = 宝能内斗期间土地诉讼计提预计负债11.78亿（一次性）
- 2023年暴增 = 诉讼和解转回（一次性）
- 核心调味品业务实际稳定在5-7亿利润水平

### 2. 趋势修正与 snapshot 的差异
- Snapshot 81（只看最新期数据）：盈利能力13 + 成长23 + 健康25 + 估值13 = 高分
- 趋势修正 -8：ROE从44%持续降至9.4%（过去3年趋势恶化）
- 修正后73：真实反映了"好行业+好公司但处于下行周期"的状态

### 3. 基本面拐点 vs 趋势下行矛盾
2026Q1营收+19.88%/净利+45.11%创历史新高，但4年趋势仍在下降通道。
- 趋势修正系统捕捉的是**过去4年的轨迹**，不包含Q1拐点
- Q1拐点已在成长性维度体现（成长23/25）
- 趋势修正和季度增长是互补信息
