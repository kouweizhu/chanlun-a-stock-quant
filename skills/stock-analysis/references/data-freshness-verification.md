# 数据时效性校验 — 参考手册

## 问题背景

Baostock 是盘后数据源，只在每个交易日收盘后更新一次。如果在交易时段（工作日 9:30-15:00）运行分析，`quick_chanlun.py` 返回的 `current_price` 是最新日线的收盘价，而非实时价。

## 实时价获取（实测可用）

### 方案1：Tavily 搜索雪球（推荐，最稳定）

```bash
# 搜索词示例
tavily_search("珀莱雅 603605 股价")
# → 返回结果含雪球实时行情
# "珀莱雅. 66.90. +5.09 +8.23%. SH603605, 06-01 13:31:51（北京时间）"
```

原理：雪球页面直接显示实时价+涨跌幅，Tavily 搜索结果会抓取该摘要行，无需额外API。

### 方案2：Tavily 搜索东方财富

```bash
tavily_search("603605 珀莱雅 实时行情")
# → 东方财富页面摘要含实时价
```

### 方案3：Bing 中文搜索

```
mcp_bing_cn_bing_search(query="珀莱雅 603605 收盘价")
# → 东方财富/搜狐证券等来源
```

## 判断交易时段的规则

Python 判断逻辑：

```python
from datetime import datetime
now = datetime.now()
is_weekday = now.weekday() < 5  # 周一到周五
is_trading_hours = (now.hour == 9 and now.minute >= 30) or (10 <= now.hour <= 11) or (13 <= now.hour <= 14) or (now.hour == 15 and now.minute == 0)
is_trading_session = is_weekday and is_trading_hours
```

## 滞后程度判定

| 滞后程度 | 判断标准 | 处理方式 |
|:--------|:---------|:---------|
| **无滞后** | 实时价与Baostock收盘价差异<2% | 直接使用Baostock数据，标注日期 |
| **轻度滞后** | 差异2-5%，价格仍在同一中枢内 | 报告中标注"盘中价波动"，不修改评分 |
| **显著滞后** | 差异>5%，或价格已突破/跌破中枢边界 | 标注+给出修正评分估算 |
| **跨周末滞后** | 周一盘中数据基于上周五收盘 | 标注"跨周末，注意跳空风险" |

## 评分修正示例

### 案例：珀莱雅 2026-06-01

**Baostock数据（5/29收盘）**：
- 收盘价：61.81（中枢内部，ZG=62.55, ZD=58.91）
- 技术分：32（中枢中轴上方+15, MACD金叉+10, 趋势向上+10, 破前低-3）

**实时雪球数据（6/1 盘中）**：
- 实时价：66.90（已突破ZG=62.55，涨幅+8.23%）

**修正评分**：
- 追加"突破中枢上沿+20" → 修正技术分 ~52
- 新向上笔可能形成 → 追加+15 → 修正技术分 ~67
- **注意**：此修正仅供用户参考，正式评分仍需等日K线确认

**报告中标注**：
> ⚠️ 当前价基于2026-05-29收盘数据（61.81）。截至06-01盘中实时价约66.90（+8.23%），已突破ZG=62.55。若K线确认，技术面应上调至关注区间。详见"可执行观察清单"条件①。

## 错误处理

如果 Tavily 搜索和 Bing 搜索都无法获取实时价：
1. 检查今天是否为非交易日（周末/节假日）
2. 告知用户"无法获取实时行情，报告基于交易所最新收盘数据"
3. 维持原有评分，但在报告中标注"数据来源受限"
