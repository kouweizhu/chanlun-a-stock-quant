# 运达股份(300772) 增收不增利矛盾案例 — 2026-05-14

> 典型矛盾案例：营收高增长(32.5%) + 正面消息面(score=75) vs ROE崩溃(4.9%) + 毛利率崩塌(7.6%) + 技术面三卖
> 最终决策：回避（综合45.4 < 50）

## 案例概要

| 维度 | 评分 | 关键数据 |
|:-----|:----:|:---------|
| 技术面 | 49 | 最新中枢[2025-09-18~2026-04-29] ZG=19.55 ZD=16.76，当前价16.46跌破ZD(三卖) |
| 基本面 | 11 | ROE 16.3%→8.2%→8.5%→4.9%，毛利率17.8%→13.7%→9.0%→7.6%，负债率84.4% |

## 核心矛盾模式：增收不增利

```
营收:   7.7% → 18.5% → 32.5%  (持续加速增长)  ✅
净利润: -32.8% → 12.2% → -26.9% (波动巨大)   ❌
ROE:    16.3% → 8.2% → 8.5% → 4.9% (持续崩溃) ❌❌
毛利率: 17.8% → 13.7% → 9.0% → 7.6% (持续下降) ❌❌
负债率: 84.4% (极高杠杆)                      ❌❌
```

## 否决触发链

1. ROE连续下降：16.3→8.2→8.5→4.9 (趋势明显恶化)
2. 负债率84.4% > 70% → ROE连降3年+负债率>70% → 降级2档
3. 技术面三卖(跌破中枢ZD=16.76) → 额外扣分
4. 基本面11分 < 40 → 即使技术面好也只能轻仓（此处技术面也差）

## 正面消息面为何不改变决策

消息面 score=75 (大幅利好)，但：
- 消息面权重仅30%，无法抵消基本面(11分)和技术面(49分)的劣势
- 正面消息（订单增长、中标领先）属于**量的增长**，而基本面问题出在**盈利质量**
- 增收不增利：营收增长但毛利率持续下降，说明行业竞争加剧或成本失控
- 技术面三卖确认价格结构恶化，短期反弹预期低

## 决策规律总结

当出现以下**三重矛盾**时，决策应偏向保守：
1. **基本面崩溃**（ROE持续下降+毛利率收缩+负债率高）→ 公司质地差
2. **技术面恶化**（三卖/跌破中枢/连续向下笔）→ 价格结构不支持
3. **消息面正面**（订单增长/行业景气）→ 量的增长无法解决盈利问题

→ 优先相信基本面和技术面，消息面的正面信号在盈利质量恶化面前不可靠
→ 决策方向：回避/观望，直到基本面出现实质性改善（毛利率回升、ROE止跌）
