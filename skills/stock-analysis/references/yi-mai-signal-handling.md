# 一买/一卖信号处理指南

## 一买信号概述

**一买（第一类买点）** 是缠论中最强的买入信号，标志下跌趋势通过底背驰确认终结。技术面评分的最高单项加分（+25分）就是为此设计。

### 识别特征

| 特征 | 说明 |
|:----|:-----|
| 级别 | 日线一买为最强, 30分钟一买次之 |
| 置信度 | `quick_chanlun.py` 输出的 `confidence_score` 字段 |
| 背驰验证 | `reason` 字段包含 "下跌趋势背驰/底背驰" 关键字 |
| 出现位置 | 下跌趋势末端, 连续向下笔后, MACD面积/力度缩小 |

## 评分处理

### 一买与卖点惩罚的互斥关系

当一买出现在卖点信号**之后**时，卖点被"消耗"：

```
时间线:  三卖(03-17) → 继续下跌 → 一买(04-27) → 当前价(04-30)
卖点惩罚:     -8  ← 若孤立看 → 0 (被一买覆盖)
```

**核心逻辑：** 一买标志着下跌趋势的终结, 卖点已完成其历史使命。继续扣减卖点惩罚等于"双重处罚"——既惩罚了卖点的出现, 又忽略了反转信号的出现。

### 判断规则

| 场景 | 处理 |
|:----|:-----|
| 一买后 **无** 卖点信号存在于该笔区间 | 不涉及互斥, 正常加分 |
| 一买(置信度≥3) **出现在** 卖点信号之后 | **卖点惩罚归零**（被消耗） |
| 一买(置信度<3) | 卖点惩罚保留（买入信号不够强, 假设反转未确认） |
| 一买后出现了新的卖点 | 新卖点正常扣分, 与旧一买无关 |

### 实战案例：分众传媒(002027) 2026-04-30

| 事项 | 日期 | 价格 | 置信度 |
|:----|:----:|:----:|:------:|
| 三卖 | 2026-03-17 | 7.02 | 2 |
| 一买 | 2026-04-27 | 6.04 | **4** |

**评分计算：**
- 按规则, 卖点应在近期卖点条件中扣 -8
- 但一买(置信度4)出现在该卖点之后 → **卖点被消耗**, 不扣 -8
- 技术分从 31 → 39

## 技术面评分中的一买加分

一买是**只有近1个月内有买点信号(+25)** 这个加分支能捕捉的。在评分时应注意：

1. **时效性**：04-27出现的一买 → 04-30分析 → 仅隔3天, 属于"近1个月", 加 +25
2. **唯一性**：一买和三买/二买不会同时出现, 它们是互斥的。同一个买点信号只加一次分
3. **卖点+一买连续出现的含义**：三卖后出一买 = 完整的"跌→底"循环已完成, 是趋势反转的典型模式

## 报告中的突出显示

当一买信号出现时（特别是置信度≥4）, 分析报告应在快速结论和技术面部分**醒目突出**：

```
⭐ **关键信号: 2026-04-27 一买 @6.04 (置信度4) — 8个月下跌趋势首次底背驰反转信号**
```

并在核心技术面矛盾中明确:
> 一买已出现(看多), 但价格仍在中枢下方(看空) → 反转初期, 未确认

## 一买 vs 笔级别盘背: 尺度差异（重要）

**关键发现（2026-05-13 石头科技案例）：** `quick_chanlun.py` 的一买检测算法与技能中描述的笔级别盘背检测（2.4c节）使用**不同尺度的比较**，不可混为一谈。

### 两种比较尺度的区别

| 比较类型 | 比较对象 | 算法来源 | 石头科技案例 |
|:--------|:---------|:---------|:-----------:|
| **笔级别盘背**（2.4c节） | 最近两个同向向下笔的MACD面积 | 主Agent手动计算 | 笔②面积34.48 vs 笔④面积38.27 → 111% ❌ |
| **算法一买检测**（quick_chanlun.py） | 离开中枢的完整下跌段 vs 前一个更大级别下跌段的MACD面积 | 算法内部 | 面积119.60 vs 38.27 → ✅ 一买确认 |

### 为什么笔级别盘背会漏掉一买？

- 笔级别盘背只检查**最近两个同向向下笔**（通常跨度数周）
- 算法一买比较的是**跨多个中枢的完整趋势段**（可能跨度数月到数年），覆盖了从更高位置开始下跌的完整区间
- 本案例中：笔④（02-25→04-16）的MACD面积比笔②（01-07→02-02）还大（111%），因为笔④的下跌幅度更大（-28.2% vs -14.3%），MACD柱自然更长。但**更大尺度**上，从更高位开始的整个下跌趋势（面积119.60）相比更早的下跌段（面积38.27）是背驰的

### 处理规则

| 场景 | 处理方式 |
|:----|:---------|
| 算法报一买 + 笔级别盘背也确认 | 最强信号，一买加分+25，盘背加分+10（上限35） |
| **算法报一买 + 笔级别盘背不确认** | **一买加分+25仍有效**，不扣分。报告中说明"一买基于更大级别趋势背驰，非笔级别盘背" |
| 算法报一买 + 笔级别盘背不确认 + 价格已跌破一买 | 一买失效，按止损规则处理 |

### 报告中的表述模板

当出现上述第②种场景时，在报告中明确说明：

> ⚠️ 笔级别盘背不成立（面积比111%）。算法的一买是基于**更大级别**的下跌趋势背驰（多个中枢嵌套后的趋势背驰），非笔级别的简单盘背。两种比较尺度不矛盾，一买信号**不受笔级别无盘背的影响**。

### 验证方法

当算法报一买但笔级别无盘背时，可通过以下方式验证一买可信度：

1. 检查一买后的**向上笔是否成立**（即价格从一买位置反弹并形成新高点）
2. 检查**MACD金叉**是否已经形成
3. 检查一买的 **confidence_score ≥ 4**
4. 如果以上三点都满足，一买可信度极高，不受笔级别无盘背影响

## 常见误判防范

| 误判 | 真实情况 | 防范 |
|:----|:---------|:-----|
| 把反弹当一买 | 一买必须有MACD底背驰验证 | 检查 `reason` 字段是否包含"背驰" |
| 把30分钟一买当日线一买 | 级别不够 | 检查 `level` 字段（日线一买 level=1） |
| 一买后立刻重仓 | 一买需确认（突破ZD或形成二买） | 观察清单: 突破ZD之前不宜重仓 |
| 一买后不设止损 | 一买可能失败 | 止损位: 一买最低点下方 3-5% |
