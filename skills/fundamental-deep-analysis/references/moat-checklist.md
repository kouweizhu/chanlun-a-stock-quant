# 护城河评估清单

巴菲特："投资的关键，在于找到那些有宽阔护城河保护的业务。"

---

## 五种护城河类型

### 类型①：无形资产护城河

#### 品牌护城河

**判断问题**：消费者是否愿意为品牌支付**显著**溢价？（不是5%，而是30-50%以上）

**A股典型案例**：
- 高端白酒：一瓶普通白酒50元，某品牌卖1000元——溢价来自品牌
- 中药老字号：同样配方的药，老字号溢价明显

**检查清单**：
- [ ] 品牌溢价能否持续5年以上？
- [ ] 竞争对手能否通过广告/营销快速复制品牌？
- [ ] 品牌在消费者心智中的地位是在增强还是减弱？
- [ ] 年轻一代消费者是否还认可这个品牌？

**评分**：
- 5分：独占性品牌，不可替代（如茅台）
- 3分：有品牌优势，但存在替代选择
- 1分：有知名度但无溢价能力

#### 专利护城河

**判断问题**：公司是否有受法律保护的技术垄断？

**检查清单**：
- [ ] 核心专利还有多少年有效期？
- [ ] 竞争对手能否绕过专利？
- [ ] 专利到期后，公司靠什么维持优势？
- [ ] 研发管线是否持续产出新专利？

**评分**：
- 5分：核心专利构成不可绕过的壁垒，且专利组合持续更新
- 3分：有专利保护但存在替代技术路线
- 1分：专利即将到期且无后续管线

#### 许可证护城河

**判断问题**：政府牌照是否构成不可逾越的进入壁垒？

**A股典型案例**：免税牌照（中国中免）、金融牌照、烟草专卖

**评分**：
- 5分：垄断性牌照，仅此一家
- 3分：有限竞争牌照（如银行、保险）
- 1分：牌照可申请，不构成真正壁垒

---

### 类型②：转换成本护城河

**核心问题**：客户换掉这家公司的产品，要付出什么代价？

**代价类型**：
- 金钱成本：新系统购买费、数据迁移费
- 时间成本：重新培训、重新部署
- 风险成本：切换过程中出错导致业务中断
- 关系成本：失去已有的定制化配置和历史数据

**高转换成本行业**：
- 企业级软件（ERP、CRM）：换系统折腾半年起步
- 金融数据终端（Wind、Bloomberg）：所有分析师都用，换不动
- 医疗信息系统：病历数据迁移代价极大
- 工业自动化：设备重新调试认证

**低转换成本行业**：
- 日用消费品：换牌子零代价
- 简单App：卸载重装一分钟
- 普通餐饮：今天这家明天那家

**检查清单**：
- [ ] 客户换供应商需要多长时间的过渡期？
- [ ] 转换期间业务是否会受影响？
- [ ] 竞争对手要花多大力气才能"挖"走客户？
- [ ] 公司是否在主动增加客户的转换成本（如生态锁定）？

**评分**：
- 5分：转换成本极高，客户几乎不可能换
- 3分：转换有一定成本，但并非不可行
- 1分：转换几乎零成本

---

### 类型③：网络效应护城河

**核心特征**：产品对每个用户的价值，随着用户总数增加而增加。

**两种网络效应**：
- 直接网络效应：微信——所有朋友都在上面，你不可能换
- 间接网络效应：淘宝——买家越多→卖家越多→商品越多→买家更多

**检查清单**：
- [ ] 用户数增加是否直接提升了产品的价值？
- [ ] 竞争对手是否因为"人不够多"而无法形成有效竞争？
- [ ] 网络效应是本地化还是全球性的？
- [ ] 是否存在"多归属"（用户同时用多个平台）？

**A股注意**：纯网络效应公司多在港股/美股上市。A股中体现网络效应的主要是平台型公司（如电商、支付）。

**评分**：
- 5分：强网络效应，用户越多越离不开
- 3分：有网络效应但存在多平台竞争
- 1分：无网络效应

---

### 类型④：成本优势护城河

**核心问题**：公司能否在更长时间内维持比竞争对手更低的成本？

**成本优势来源**：

| 来源 | 说明 | 可持续性 |
|------|------|:---:|
| 规模经济 | 产量大→分摊固定成本 | ⭐⭐⭐⭐ |
| 地理位置 | 靠近原材料/低成本劳动力 | ⭐⭐⭐⭐⭐ |
| 资源禀赋 | 独有的矿产资源 | ⭐⭐⭐⭐⭐ |
| 流程优势 | 独特的生产工艺/管理方法 | ⭐⭐⭐ |
| 垂直整合 | 控制了上下游 | ⭐⭐⭐⭐ |

**检查清单**：
- [ ] 成本优势的来源是什么？竞争对手能否复制？
- [ ] 成本优势是绝对值优势（真的更便宜）还是阶段性优势（别人也可以做到）？
- [ ] 成本优势能否维持5年以上？
- [ ] 规模效应是否已经到头？（边际递减）

**评分**：
- 5分：结构性成本优势（地理位置/资源/牌照），不可复制
- 3分：规模优势，但竞争对手可能在规模上追赶
- 1分：无明显成本优势

---

### 类型⑤：高效规模护城河

**核心特征**：市场容量有限，只能容纳1-2家高效运营，新进入者来了也赚不到钱。

**典型场景**：
- 区域性公用事业（供水、供电、燃气）
- 特种化工材料（全球市场每年只够100亿需求）
- 利基市场的隐形冠军

**检查清单**：
- [ ] 这个市场的容量是否确实有限？
- [ ] 现有公司是否已经占据最优规模？
- [ ] 如果新进入者进入，是否能同时盈利？
- [ ] 行业是否在增长？（如果市场扩大，可能容纳更多玩家）

**评分**：
- 5分：市场天花板低，新进入者无利可图
- 3分：市场有限但仍在增长，可能吸引新玩家
- 1分：市场规模大，随时有新进入者

---

## 综合护城河评级

| 评级 | 标准 | 投资含义 |
|:----:|------|---------|
| **宽阔** ⭐⭐⭐⭐⭐ | 2种以上强护城河，且持续加深 | 长期重仓候选 |
| **较宽** ⭐⭐⭐⭐ | 1-2种护城河，稳定维持 | 可以持有但需跟踪 |
| **狭窄** ⭐⭐⭐ | 有护城河但可能在削弱 | 谨慎持有，关注变化 |
| **脆弱** ⭐⭐ | 护城河正在被侵蚀 | 考虑减仓 |
| **无护城河** ⭐ | 产品同质化，完全竞争 | 不应长期持有 |

## 护城河侵蚀信号

以下信号出现时，护城河可能在削弱：

- [ ] 毛利率连续3年下降 → 定价权在减弱
- [ ] 市场份额连续下滑 → 竞争力在流失
- [ ] 研发投入占收入比下降 → 在吃老本
- [ ] 客户流失率上升 → 转换成本下降
- [ ] 出现强力竞争对手 → 行业壁垒降低
- [ ] 替代品/替代技术出现 → 护城河可能失效
- [ ] 大客户开始自建能力 → 去中介化威胁
