# 四层基本面分析框架详细方法论

源自价值投资经典方法论，结合A股市场特点调整。

---

## 第一层：行业研究

### 1.1 行业空间

**关键问题**：这门生意的天花板有多高？

| 维度 | 分析方法 | 数据来源 |
|------|---------|---------|
| 市场规模 | 当前行业总营收/总产量 | 行业协会报告、国家统计局 |
| 增速 | 过去3-5年CAGR + 未来3年预期 | 券商研报、行业白皮书 |
| 阶段 | 导入期/成长期/成熟期/衰退期 | 增速+渗透率判断 |
| 增量 vs 存量 | 增速 > GDP → 增量；< GDP → 存量 | 对比GDP增速 |

**A股特别关注**：
- 政策驱动型行业（新能源、半导体）：关注补贴退坡节奏
- 消费升级型行业（高端白酒、医疗服务）：关注人均收入增长
- 老龄化受益型（医疗器械、养老服务）：确定性高

### 1.2 竞争格局

**关键问题**：这个行业是"老大吃肉"还是"大家喝汤"？

```
集中度判断：
- CR3 > 50%：寡头格局，龙头有定价权
- CR3 20-50%：分散竞争，龙头有优势但不大
- CR3 < 20%：完全竞争，很难有持续超额利润
```

**趋势判断更重要**：
- 集中度在提升 → 龙头份额扩大 → 利好龙头
- 集中度在下降 → 新进入者蚕食 → 龙头承压

**竞争手段分析**：
- 价格战：最差，所有人利润被压缩
- 品牌差异化：较好，龙头可维持溢价
- 技术壁垒：好但可能被颠覆
- 渠道壁垒：较好，新进入者难突破

### 1.3 行业壁垒

**进入壁垒类型**：

| 壁垒类型 | 强度 | 典型案例 |
|---------|:---:|---------|
| 政府牌照/许可 | 极强 | 烟草、博彩、金融牌照 |
| 专利保护 | 强但有期限 | 创新药（20年专利期） |
| 品牌积累 | 强 | 高端白酒（数十年积累） |
| 规模效应 | 中强 | 家电龙头（成本优势） |
| 技术门槛 | 中 | 芯片制造（高资本+技术） |
| 渠道网络 | 中 | 乳制品（冷链+终端网点） |

### 1.4 A股政策风险评估

**必问的三个问题**：
1. 这个行业会不会被政策"团灭"？（参考教育双减）
2. 这个行业受集采/限价影响吗？（医药、公用事业）
3. 政策方向是扶持还是打压？

**高风险行业标记**：
- 强监管行业（金融、房地产、互联网平台）
- 政府定价行业（电力、水务、燃气）
- 政策敏感行业（教育、游戏、影视）

## 第二层：公司研究

### 2.1 商业模式分析

#### 商业模式分类矩阵

|  | 一次性交易 | 持续性收入 |
|--|----------|----------|
| **产品型** | 普通制造业、房地产 | 打印机+墨盒、手机+生态 |
| **服务型** | 建筑公司、咨询 | SaaS软件、会员订阅 |

#### 商业模式评分维度（每项0-5分）

| 维度 | 好（5分） | 差（1分） |
|------|---------|---------|
| 定价权 | 能持续提价 | 被迫降价竞争 |
| 资本需求 | 轻资产，不需大量CAPEX | 每次扩张都要建厂买设备 |
| 现金流 | 预收款，先收钱后交货 | 应收款堆积，客户拖欠 |
| 复购率 | 高频复购 | 一次性买卖 |
| 可复制性 | 标准化，容易扩张 | 项目制，每次重新投入 |

#### 商业模式四大陷阱

1. **烧钱扩张陷阱**：收入靠补贴驱动，补贴停止用户跑光 → 警惕现金流持续为负
2. **项目制陷阱**：做一单赚一单，收入高度依赖少数大客户
3. **产业链弱势陷阱**：上下游都是大佬，账期极长，利润被两头挤压
4. **技术迭代陷阱**：现有优势可能在5年内被新技术颠覆

### 2.2 护城河评估

详见 `moat-checklist.md`。

五种护城河类型：
1. **无形资产**（品牌/专利/牌照）
2. **转换成本**（用惯了就很难换）
3. **网络效应**（用的人越多越值钱）
4. **成本优势**（做到比所有人都便宜）
5. **高效规模**（市场小，只能容纳少数玩家）

**护城河强度综合评级**：
- **宽阔**：有2种以上护城河，且持续加深 → 长期超额利润
- **狭窄**：有1种护城河，但可能在削弱 → 有限竞争优势
- **无护城河**：产品同质化，完全竞争 → 回避

### 2.3 管理层评估

**诚信维度**（一票否决）：
- [ ] 有无财务造假记录？
- [ ] 有无大股东侵占上市公司利益？
- [ ] 关联交易是否频繁且不透明？
- [ ] 大股东是否频繁减持？

**能力维度**：
- [ ] 过去的战略决策是否正确？
- [ ] 主营业务是否聚焦？（警惕"多元化"）
- [ ] 行业地位是在提升还是下降？

**激励维度**：
- [ ] 管理层持股比例？
- [ ] 薪酬与股东利益是否一致？
- [ ] 分红政策是否稳定？

## 第三层：财务研究

### 3.1 ROE 杜邦拆解

```
ROE = 净利润率 × 资产周转率 × 权益乘数
    = 赚钱含金量 × 资产效率 × 杠杆倍数
```

**三种高ROE模式与投资价值**：

| 模式 | ROE来源 | 可靠性 | 代表行业 |
|------|---------|:---:|---------|
| 高利润率型 | 净利润率高 | ⭐⭐⭐⭐⭐ 最可靠 | 高端白酒、软件、医药 |
| 高周转型 | 资产周转快 | ⭐⭐⭐⭐ 较可靠 | 零售、连锁餐饮 |
| 高杠杆型 | 权益乘数大 | ⭐⭐ 需警惕 | 银行、房地产 |

**ROE 评估标准**：
- ROE < 10%：差
- ROE 10-15%：一般
- ROE 15-20%：较好
- ROE > 20%：优秀
- ROE > 30%：需要甄别（可能是高杠杆）

**关键：持续性**。连续5年以上ROE > 15% 才有意义。

### 3.2 三率合一分析

| 类型 | 毛利率 | 净利率 | 负债率 | 特征 |
|------|:-----:|:-----:|:-----:|------|
| 高富帅型 | >50% | >20% | <30% | 最理想的生意 |
| 现金奶牛型 | >40% | >15% | <40% | 稳定分红 |
| 苦命打工型 | <20% | <5% | >60% | 回避 |
| 大力出奇迹型 | 高 | 低 | 高 | 需要现金流的验证 |

### 3.3 利润含金量

```
利润含金量 = 经营活动现金流净额 / 净利润

> 100%：优秀，赚的是真钱
80-100%：正常
< 80%：警惕，利润可能是纸面的
< 50%：严重警告，远离
```

### 3.4 增长质量检查

- [ ] 利润增速 vs 收入增速：是否匹配？
- [ ] 应收账款增速：是否快于收入增速？
- [ ] 商誉/总资产：是否 > 30%？（并购增长嫌疑）
- [ ] 前5大客户集中度：是否 > 50%？（单一客户依赖）

## 第四层：估值研究

### 4.1 各行业适用估值指标

| 行业 | 主指标 | 辅指标 | 合理区间 |
|------|--------|--------|---------|
| 消费龙头 | PE | PS | 25-40倍 |
| 科技/成长 | PEG | PS | PEG 0.8-1.5 |
| 金融 | PB | PE | PB 0.5-1.2 |
| 医药 | PE+PEG | — | PE 25-40 |
| 周期 | PB | 逆向PE | PB < 1 |
| 公用事业 | 股息率 | PE | PE 15-25 |

### 4.2 历史分位法

- 当前PE处于近5年什么分位？
- < 20%分位：相对低估
- 20-50%分位：合理偏低
- 50-80%分位：合理偏高
- > 80%分位：相对高估

### 4.3 PEG 估值法

```
PEG = PE / 年利润增长率(%)

PEG < 0.5：极度低估
PEG 0.5-0.8：低估
PEG 0.8-1.2：合理
PEG 1.2-2.0：偏贵
PEG > 2.0：高估
```

### 4.4 安全边际

```
安全边际 = 1 - (当前股价 / 合理估值)

> 30%：安全边际充足，好买点
20-30%：有一定安全边际
10-20%：安全边际偏小
< 10%：几乎无安全边际
```

## A股特殊考量

### 分红是检验真金白银的标准
- 持续分红 > 5年的公司值得信任
- 从来不分红的公司，利润可能只是纸面富贵

### 政策风险是第一道防火墙
- 选择行业比选择个股更重要
- 避开政策风险大的行业（教育、房地产、部分互联网）

### A股的机会往往在"坏消息"里
- 行业遭遇短期利空 → 优质公司被错杀
- 市场整体恐慌 → 遍地黄金
- 关键：区分"短期利空"和"永久性损失"
