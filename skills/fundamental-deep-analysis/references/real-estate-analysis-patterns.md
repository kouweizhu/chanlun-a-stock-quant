# 房企分析专属框架

对房地产公司的深度分析，在 standard 四层框架（行业→公司→财务→估值）基础上，需针对行业特性增加以下专项分析维度。每次房企分析前先扫描此清单。

---

## 一、国资属性分级（中国房企特有）

不要笼统说"国资背景"，要明确定位到以下等级：

| 等级 | 定义 | 判断依据 | 典型例子 |
|------|------|---------|---------|
| **国有控股** | 国资持股>30%或实质上控制董事会 | 股权穿透至最终实控人为国资委/财政部，且持股比例高 | 保利发展(中国保利集团)、招商蛇口(招商局集团) |
| **国有实际控制** | 国资第一大股东+管理层已接管 | 持股<30%但实质性主导董事会和运营 | 万科(深铁27.18%，2025年起管理层全面换血) |
| **国资参股混合所有制** | 国资持股<10%，无实控人 | 国资仅是财务投资者/二股东，不主导运营 | 金地集团(福田投控<8%) |
| **纯民营** | 无国资持股 | 实控人为自然人或民营企业 | 碧桂园、龙湖(2026年前) |

**分析要点**：
- 等级决定了"政府救助意愿"的强度：国有控股 > 国有实际控制 >> 国资参股 > 纯民营
- 救助不是无限的——即使是国有控股，政府救助也有底线（防止系统性风险，而非兜底股东）
- 查看历史救助记录（股东借款、项目收购、担保增信）比看声明更有说服力

---

## 二、债务结构多层拆解（核心差异化分析）

房企的"公开市场债务清零"不等于债务安全。必须分层分析：

### 第1层：公开市场债务（债券/中票/ABS）
- **特征**：最刚性，到期必须兑付，违约即触发公开违约事件
- **来源**：查看年报"应付债券"明细 + 公告到期兑付情况
- **关键问题**：还有多少存续？什么时候到期？是否有展期？

### 第2层：银行借款（通常占90%+）
- **特征**：可协商展期/借新还旧，但有续贷风险
- **来源**：年报"短期借款"+"长期借款"+"一年内到期非流动负债"
- **关键指标**：
  - 银行借款占比（越高越好，说明银行愿意放款）
  - 现金短债比 = 货币资金 / 短期有息负债（>1.0安全，<0.5危险）
  - **⚠️ 现金质量调整**：账面现金中包含预售监管资金（不可自由动用），需要扣除后再计算。可参考年报附注中"受限货币资金"明细

### 第3层：经营性负债（无息但有偿付压力）
- 应付账款（欠供应商的工程款、材料款）
- 其他应付款（合联营企业往来款、少数股东垫付借款）
- 合同负债（预收房款——不是债但要靠交房消化）
- 应交税费

### 第4层：合作项目或有负债（隐性风险）
- 权益比例低的合作开发项目，金地对合作方融资可能有担保义务
- 合作方若出险，可能需要兜底
- 查看：年报"对外担保"明细、受限资产（存货抵押、股权质押）规模

### 第5层：受限资产（隐含债务）
- 货币资金保证金、存货抵押、投资性房地产抵押、股权质押
- 受限资产规模/总资产比例——越高说明剩余可抵押空间越小
- 来源：年报附注"截至报告期末主要资产受限情况"

### 分析流程
```
第1步：确认公开债是否清零/存续规模
    ↓
第2步：确认银行借款总额 + 现金短债比（调整后）
    ↓
第3步：确认应付账款+其他应付款总额（判断经营压力）
    ↓
第4步：查对外担保规模 + 合作方信用状况
    ↓
第5步：评估受限资产比例，判断再融资空间
```

## 三、现金流质量诊断

房企的"经营性现金流净流入"需要仔细解读：

| 情景 | 解读 | 案例 |
|------|------|------|
| 经营现金流大幅正流入 + 销售回款同步增长 | 健康，真金白银 | — |
| 经营现金流大幅正流入 + 销售回款下降 | **通常是收缩规模、减少拿地、压缩开支的结果，不可持续** | 金地2024年经营现金流136亿、2025年骤降至0.16亿 |
| 经营现金流为负 + 筹资现金流负 | 最危险——既不能造血也融不到钱 | 万科2025年 |
| 筹资现金流为负大幅收窄 | 说明偿还借款减少，不一定是好事 | 金地2025年筹资净流出-95亿（2024年为-236亿） |

**关键行业特性**：
- 房企的经营现金流转正往往不是"生意变好"，而是"不买地了、不开工了"
- 真正的信号要看：销售回款（销售商品收到的现金）的趋势
- 现金短债比需要调整预售监管资金——账上500亿现金可能只有200亿能自由调配

## 四、资产质量评估（减值风险判断）

房企净资产大幅缩水的主要来源是**资产减值**。需要判断减值是否出清：

### 存货减值是核心
- 房企最大的资产是存货（土地+在建+已建成未售）
- 2021年前高价拿的地块，在2025-2026年市场价格下需要大幅减值
- 判断减值是否充分：看减值后的毛利率（如果结算毛利率仍只有个位数，说明还有减值空间）

### 投资性房地产
- 商业/办公/产业园资产——是否有公允价值变动？
- 出租率变化趋势（出租率下降→估值下调压力）

### 应收账款/其他应收款——联营合营公司敞口
- 合作开发模式下，其他应收款可能包含大量对合作方的垫款
- 合作方出险→这些应收款可能坏账
- 查看：年报附注中其他应收款的账龄结构和欠款方性质

### 商誉
- 房企商誉一般不大，但若有物业/代建业务收购产生的商誉，也需要关注

## 五、土地储备质量评估

土地储备是房企的核心资产，分析维度：

| 维度 | 高质量信号 | 低质量信号 |
|------|-----------|-----------|
| 城市能级 | 一二线占比>70% | 三四线为主 |
| 权益比例 | >50%（项目有实际控制权） | <30%（利润被少数股东大量稀释） |
| 获取时间 | 2022年后低点拿地 | 2019-2021年高位拿地 |
| 可售比 | 已开工占比高 | 大量未开工（需额外投资才能变现） |
| 去化速度 | 当年新推去化率>60% | 持续积压 |

## 六、行业周期分析与估值修复三阶段模型

适用于2025-2026年房地产行业的情景分析框架：

| 阶段 | 触发条件 | 估值逻辑 | 受益标的类型 |
|------|---------|---------|-------------|
| **① 折价收敛** | 销售数据持续改善、核心城市房价企稳、企业未违约 | PB修复（从极度悲观回归中性折价） | 所有低PB房企 |
| **② 减值压力缓解** | 房价不再下跌→不必再大额计提减值 | 亏损收窄→净资产止跌 | 减值充分的房企 |
| **③ 盈利驱动估值切换** | 利润转正→市场从PB定价转向PE定价 | PE×Earnings估值 | 头部国央企 |

**当前行业位置判断方法**：
- 机构一致预期汇总——对比多家券商（中信/银河/国信/浦银等）研报中的销售预测、投资预测
- 关注以下数据链：二手房成交量（先行指标）→ 新房定价 → 房企拿地意愿 → 库存去化速度
- 行业底部通常伴随以下特征同时出现：
  - 二手房成交量连续4-6个月回升
  - 核心城市二手房挂牌量下降
  - 租金回报率超过存款利率
  - 新开工面积仅为高点30%以下（供给出清信号）

## 七、可比公司多维度对比

分析一家房企时，至少选取2-3家可比公司做横向对比：

| 维度 | 核心指标 |
|------|---------|
| 规模 | 总资产、营收、销售金额 |
| 估值 | PB（最核心，因为PE通常为负）、市值 |
| 国资安全垫 | 国有控股→国有实控→国资参股→纯民营 |
| 亏损程度 | 归母净利润、ROE、减值侵蚀 |
| 债务安全 | 有息负债率、现金短债比（调整后）、银行借款占比 |
| 非房业务 | 物业在管面积、代建签约面积、持有型物业租金收入 |

**典型房企PB区间参考（2026年）**：
- 纯国资龙头（保利/招商）：0.6-0.8x PB
- 国有实控（万科）：0.3-0.4x PB
- 混合所有制（金地）：0.2-0.3x PB
- 已出险民营：0.1x以下 PB

## 八、执行检查清单

每次分析房企前，完成以下检查：

- [ ] 国资属性分级确认（控股/实控/参股/民营）
- [ ] 公开债存续/展期状态确认
- [ ] 银行借款占比 + 现金短债比（调整后）
- [ ] 受限资产规模 / 总资产
- [ ] 对外担保总额（对合作方）
- [ ] 2021-2022年高价拿地占比
- [ ] 土储城市能级结构
- [ ] 经营现金流质量评估（销售回款趋势）
- [ ] 物业/代建等非房业务营收及趋势
- [ ] 可比公司PB对比
- [ ] 至少3家券商行业观点汇总
