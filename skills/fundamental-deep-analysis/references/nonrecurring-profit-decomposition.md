## 案例1：分众传媒(002027) — 2025年报 "净利润-42% = 假摔"

### 数据信号

| 指标 | 2024年报 | 2025年报 | 同比变化 |
|------|:-------:|:-------:|:-------:|
| 营收 | 122.62亿 | 127.59亿 | **+4.05%** ✅ |
| 扣非净利润 | 47.02亿 | 27.42亿 | -41.74% ❌ |
| 归母净利润 | 51.55亿 | 29.46亿 | -42.85% ❌ |
| 经营现金流 | 66.42亿 | **72.09亿** | **+8.54%** ✅ |
| 毛利率 | 66.26% | **70.48%** | **历史新高** ✅ |

### 矛盾点

营收增长4%、毛利率创新高、经营现金流增长8%——三个盈利指标却暴跌42%。矛盾明显指向**非经常性损益**。

### 定位过程

1. **搜索** → `"分众传媒 计提 减值"` → 发现2026年1月公告：对数禾科技计提长期股权投资减值21.53亿
2. **搜索** → `"分众传媒 数禾科技"` → 数禾科技因央行"9号文"（助贷新规）经营恶化，分众2026年1月以7.91亿清仓退出
3. **确认性质** → 减值21.53亿为**非现金项目**（不影响现金流，不消耗现金）

### 核心经营净利润还原

```
2025年报归母净利润:       29.46亿
+ 计提减值(非现金):       21.53亿
= 还原后核心净利润:       51.00亿  (+8.5% vs 2024年51.55亿)
```

### 2026Q1的镜像案例

对称现象：2026Q1归母净利润+57.65%，但扣非仅+7.88%。

```
归母净利润暴增原因:
  2026Q1完成数禾股权交割 → 资本公积转投资收益5.65亿
  这是会计上的"解冻"操作, 不反映主营业务变化
  
核心结论: 
  2026Q1扣非增长7.88% = 真实业务增速
  净利润57.65% = 假增长 (一次性收益)
```

### 估值修正（关键）

```
TTM PE = 908亿 / 29.46亿 = 30.8x → 看似很贵
修正PE = 908亿 / (29.46+21.53)亿 = 17.8x → 合理偏低
前瞻PE = 908亿 / 62亿(机构一致预期) = 14.6x → 低估
```

如果不做非经常性损益分解，TTM PE 30.8x 会直接导致"估值过贵"误判。

### 教学要点

| 信号 | 含义 | 操作 |
|------|------|------|
| 净利润-扣非净利润 两者增速方向一致 | 非经常性损益方向明确 | 按"非现金 vs 现金"分类还原 |
| 净利润↑但扣非↓ | 利润增长靠一次性收益 | 扣非增速才是真实增长 |
| 净利润↓但扣非也↓（剪刀差小） | 利润下降有一次性因素 | 搜索公告定位具体项目 |
| 经营现金流稳定/增长 + 净利润暴跌 | 大概率是非现金减值 | 加回减值评估核心利润 |
